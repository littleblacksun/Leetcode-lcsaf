## 2.3 求子数组个数

### 2.3.1 越短越合法型滑动窗口

#### 题目 1

![题目截图](./figure/Pasted%20image%2020260828113445.png)

**思路**

枚举子数组右端点 right，如果发现子数组不满足要求，就缩小窗口，也就是增大左端点 left。

内层循环结束后，[left,right] 这个子数组是满足题目要求的。由于子数组越短，越能满足题目要求，所以除了 [left,right]，还有 [left+1,right],[left+2,right],…,[right,right] 都是满足要求的。也就是说，当右端点固定在 right 时，左端点在 left,left+1,left+2,…,right 的所有子数组都是满足要求的，这一共有 right−left+1 个，加到答案中。

**解答**

```java
class Solution {
    public int numSubarrayProductLessThanK(int[] nums, int k) {
        if(k<=1){
            return 0;
        }
        int ans = 0;
        int prod = 1;
        int left = 0;
        for(int right = 0; right < nums.length; right++){
            prod*=nums[right];
            while(prod>=k){
                prod/=nums[left];
                left++;
            }
            ans += right-left+1;
        }
        return ans;
    }
}
```

#### 题目 4

![题目截图](./figure/Pasted%20image%2020260828121151.png)

**思路**

在遍历数组的同时，维护窗口内的元素及其出现次数。

由于绝对差至多为 2，所以用有序集合或者哈希表维护都行。**红黑树也可以，因为自带排序**

由于绝对差大于 2 就会缩小窗口，所以当窗口包含 4 个元素时，就一定会缩小窗口了。比如窗口有 1,2,3,4，绝对差等于 3。缩小窗口后，窗口至多包含 3 个不同元素。所以无论用有序集合还是哈希表，其大小是 O(1) 的，所以添加、删除和查询最值都是 O(1) 时间的。

如果窗口内的最大值与最小值的差大于 2，就不断移动左端点 left，减少窗口内的数字。

**解答**

使用哈希表维护(在left移出窗口的时候，应该判定left对应的hashmap中的值是否为0)

```java
class Solution {

    public long continuousSubarrays(int[] nums) {

        long ans = 0;

        TreeMap<Integer,Integer> t = new TreeMap<>();

        int left = 0;

        int cnt = 0;

  

        for(int right = 0 ; right<nums.length; right++){

            t.merge(nums[right],1,Integer::sum);

            while(t.lastKey() - t.firstKey() > 2){

                int out = nums[left];

                int c = t.get(out);

                if(c==1){

                    t.remove(out);

                }

                else{

                    t.put(out,c-1);

                }

                left++;

            }

            ans += right - left + 1;

        }

        return ans;

    }

}
```

**思路**

同上题。不过有一点注意，while判定中，只需要关注right即可，只要right进入窗口导致某一种花的数量超过cnt，然后移动左窗口即可

**解答**

```java
class Solution {

    public int beautifulBouquet(int[] flowers, int cnt) {

        int ans = 0 ;

        int left = 0;

        HashMap<Integer,Integer> t = new HashMap<>();

  

        for(int right = 0; right<flowers.length; right++){

            t.merge(flowers[right],1,Integer::sum);

            while(t.get(flowers[right]) > cnt){

                int out = flowers[left];

                int c = t.get(out);

                if(c==1){

                    t.remove(out);

                }

                else{

                    t.put(out,c-1);

                }

                left++;

            }

            ans += right-left+1;

        }

        return ans;

    }

}
```

### 2.3.2 越长越合法

一般要写 ans += left。

内层循环结束后，[left,right] 这个子数组是不满足题目要求的，但在退出循环之前的最后一轮循环，[left−1,right] 是满足题目要求的。由于子数组越长，越能满足题目要求，所以除了 [left−1,right]，还有 [left−2,right],[left−3,right],…,[0,right] 都是满足要求的。也就是说，当右端点固定在 right 时，左端点在 0,1,2,…,left−1 的所有子数组都是满足要求的，这一共有 left 个。

我们关注的是 left−1 的合法性，而不是 left。

#### 题目 1

![题目截图](./figure/Pasted%20image%2020260828132612.png)

**思路**

该题型主要是关注至少出现过一次，求子字符串的数目

**解答**

```java
class Solution {

    public int numberOfSubstrings(String s) {

        char[] c = s.toCharArray();

        int[] cnt = new int[3];

        int ans = 0;

        int left = 0;

        for(int right=0;right<c.length;right++){

            cnt[c[right]-'a']++;

            while(cnt[0]>0 && cnt[1]>0 && cnt[2]>0){ //判断条件，至少出现过一次

                cnt[c[left]-'a']--;

                left++;

            }

            ans+=left;

        }

        return ans;

    }

}
```

#### 题目 2

![题目截图](./figure/Pasted%20image%2020260828133952.png)

**思路**

一个变体，多了一部分求最大元素出现k次

**解答**

```java
class Solution {

    public long countSubarrays(int[] nums, int k) {

        int left = 0;

        int mAx = 0;

        int time = 0;

        long ans = 0 ;

        for(int x : nums){

            mAx = Math.max(mAx,x);

        }

        for(int right = 0; right<nums.length;right++){

            if(nums[right]==mAx){

                time++;

            }

            while(time==k){

                if(nums[left]==mAx){

                    time--;

                }

                left++;

            }

            ans += left;

        }

        return ans;

    }

}
```

#### 题目 3

![题目截图](./figure/Pasted%20image%2020260828135549.png)

**思路**

这道题同样使用hashmap来维护，统计窗口中有多少种元音字母，**不过需要注意的是：一旦遇到一个辅音字母，需要断开前面的窗口，重新定位left = right + 1；**

**解答**

```java
class Solution {

    public int countVowelSubstrings(String word) {

        char[] c = word.toCharArray();

        Map<Character, Integer> cnt = new HashMap<>();

        int ans = 0;

        int left = 0;

        int start = 0;

        for(int right = 0;right<c.length;right++){

            char ch = c[right];

            if("aeiou".indexOf(ch)<0){

                cnt.clear();

                start = left = right + 1;

                continue;

            }

  

            cnt.merge(c[right],1,Integer::sum);

            while(cnt.size()==5){

                char out = c[left];

                int g = cnt.merge(out,-1,Integer::sum);

                if(g==0){

                    cnt.remove(out);

                }

                left++;

            }

            ans += left - start;

        }

        return ans;

    }

}
```

#### 题目 4

![题目截图](./figure/Pasted%20image%2020260828141602.png)

**思路**

在这道题目中，**首先统计整个数组不同元素的数目**,用了一个hashset来统计，其次，使用hashmap来维护当前窗口中的元素个数是否与hashset中的一致即可，左移left的时候，要注意remove（hashmap中value=0的键值对）

**解答**

```java
class Solution {

    public int countCompleteSubarrays(int[] nums) {

        // 找到数值中不同元素的个数

        Set<Integer> set = new HashSet<>();

        for(int x : nums){

            set.add(x);

        }

        int k = set.size();

  

        Map<Integer,Integer> cnt = new HashMap<>(k);

        int ans = 0;

        int left = 0;

        for(int x : nums){

            cnt.merge(x,1,Integer::sum);

            while(cnt.size()==k){

                int out = nums[left];

                if(cnt.merge(out,-1,Integer::sum)==0){

                    cnt.remove(out);

                }

                left++;

            }

            ans += left;

        }

        return ans;

  

    }

}
```

#### 题目 5

![题目截图](./figure/Pasted%20image%2020260828143736.png)

**思路**

这里陷入了一个无误区，我以为是：某一个元素的对数，实际是整个子数组的对数

**解答**

```java
class Solution {

    public long countGood(int[] nums, int k) {

        Map<Integer, Integer> cnt = new HashMap<>();

        int left = 0;

        long ans = 0;

        long totalPairs = 0; // 只需要一个变量记录总对数

  

        for (int right = 0; right < nums.length; right++) {

            int inNum = nums[right];

            // 1. 右边界入窗

            // 在计数加 1 之前，当前的数量就是它能新增的对数

            // 例如：已有 2 个，再来 1 个，新增 2 对。

            totalPairs += cnt.getOrDefault(inNum, 0);

            cnt.merge(inNum, 1, Integer::sum);

  

            // 2. 收缩左边界

            // 题目要求：总对数 >= k。

            // 我们收缩直到 总对数 < k。

            while (totalPairs >= k) {

                int outNum = nums[left];

                // 先减少计数

                cnt.put(outNum, cnt.get(outNum) - 1);

                // 再减少对数

                // 移除后剩下的数量，就是减少的对数

                // 例如：原有 3 个 (3对)，移除 1 个剩 2 个 (1对)。减少了 2 对。

                // 此时 cnt[outNum] 已经是 2 了。

                totalPairs -= cnt.get(outNum);

                if (cnt.get(outNum) == 0) {

                    cnt.remove(outNum);

                }

                left++;

            }

  

            // 3. 统计答案

            // 此时 [left, right] 的总对数 < k (不满足)

            // 说明 [left-1, right] 的总对数 >= k (满足)

            // 所以以 right 结尾的合法子数组起始点可以是 0, 1, ..., left-1

            // 共 left 个。

            ans += left;

        }

        return ans;

    }

}
```

#### 题目 6

![题目截图](./figure/Pasted%20image%2020260828144802.png)

**思路**

使用中间变量less来记录还有多少种字符不同，使用diff[]来记录，每一个字符还有多少个不同
当窗口内less == 0时 说明 当前窗口内的字符串包含了word2里面的字符种类及个数

**解答**

```java
class Solution {

    public long validSubstringCount(String S, String T) {

        if(S.length()<T.length()){

            return 0;

        }

  

        char[] s = S.toCharArray();

        char[] t = T.toCharArray();

        int[] diff = new int[26];

        for(char c : t){

            diff[c-'a']++;

        }

  

        int less = 0;

        for(int d : diff){

            if(d>0){

                less++;

            }

        }

  

        long ans = 0 ;

        int left = 0;

        for(char c  : s){

            diff[c-'a']--;

            if(diff[c-'a']==0){

                less-- ;

            }

  

            while(less == 0){

                char outChar = s[left++];

                if(diff[outChar-'a']==0){

                    less++;

                }

                diff[outChar-'a']++;

            }

            ans += left;

        }

        return ans;

    }

}
```
