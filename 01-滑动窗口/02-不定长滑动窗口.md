## 2.3 求子数组个数

### 2.3.1 越短越合法型滑动窗口

#### 题目 1

![题目截图](./figure/Pasted%20image%2020260828113445.png)

**思路**

枚举子数组右端点 right，如果发现子数组不满足要求，就缩小窗口，也就是增大左端点 left。

内层循环结束后，[left,right] 这个子数组是满足题目要求的。由于子数组越短，越能满足题目要求，所以除了 [left,right]，还有 [left+1,right],[left+2,right],…,[right,right] 都是满足要求的。也就是说，当右端点固定在 right 时，左端点在 left,left+1,left+2,…,right 的所有子数组都是满足要求的，这一共有 right−left+1 个，加到答案中。

**解答**

```java
class Solution {
    public int numSubarrayProductLessThanK(int[] nums, int k) {
        if(k<=1){
            return 0;
        }
        int ans = 0;
        int prod = 1;
        int left = 0;
        for(int right = 0; right < nums.length; right++){
            prod*=nums[right];
            while(prod>=k){
                prod/=nums[left];
                left++;
            }
            ans += right-left+1;
        }
        return ans;
    }
}
```

#### 题目 4

![题目截图](./figure/Pasted%20image%2020260828121151.png)

**思路**

在遍历数组的同时，维护窗口内的元素及其出现次数。

由于绝对差至多为 2，所以用有序集合或者哈希表维护都行。**红黑树也可以，因为自带排序**

由于绝对差大于 2 就会缩小窗口，所以当窗口包含 4 个元素时，就一定会缩小窗口了。比如窗口有 1,2,3,4，绝对差等于 3。缩小窗口后，窗口至多包含 3 个不同元素。所以无论用有序集合还是哈希表，其大小是 O(1) 的，所以添加、删除和查询最值都是 O(1) 时间的。

如果窗口内的最大值与最小值的差大于 2，就不断移动左端点 left，减少窗口内的数字。

**解答**

使用哈希表维护(在left移出窗口的时候，应该判定left对应的hashmap中的值是否为0)

```java
class Solution {

    public long continuousSubarrays(int[] nums) {

        long ans = 0;

        TreeMap<Integer,Integer> t = new TreeMap<>();

        int left = 0;

        int cnt = 0;



        for(int right = 0 ; right<nums.length; right++){

            t.merge(nums[right],1,Integer::sum);

            while(t.lastKey() - t.firstKey() > 2){

                int out = nums[left];

                int c = t.get(out);

                if(c==1){

                    t.remove(out);

                }

                else{

                    t.put(out,c-1);

                }

                left++;

            }

            ans += right - left + 1;

        }

        return ans;

    }

}
```

### 2.3.2 越长越合法

一般要写 ans += left。

内层循环结束后，[left,right] 这个子数组是不满足题目要求的，但在退出循环之前的最后一轮循环，[left−1,right] 是满足题目要求的。由于子数组越长，越能满足题目要求，所以除了 [left−1,right]，还有 [left−2,right],[left−3,right],…,[0,right] 都是满足要求的。也就是说，当右端点固定在 right 时，左端点在 0,1,2,…,left−1 的所有子数组都是满足要求的，这一共有 left 个。

我们关注的是 left−1 的合法性，而不是 left。

**思路**

在这道题目中，**首先统计整个数组不同元素的数目**,用了一个hashset来统计，其次，使用hashmap来维护当前窗口中的元素个数是否与hashset中的一致即可，左移left的时候，要注意remove（hashmap中value=0的键值对）

```java
class Solution {

            set.add(x);

        }

            }
```

#### 题目 5

![题目截图](./figure/Pasted%20image%2020260828143736.png)

**思路**

这里陷入了一个无误区，我以为是：某一个元素的对数，实际是整个子数组的对数

**解答**

```java
class Solution {

    public long countGood(int[] nums, int k) {

        Map<Integer, Integer> cnt = new HashMap<>();

        int left = 0;

        long ans = 0;

        long totalPairs = 0; // 只需要一个变量记录总对数



        for (int right = 0; right < nums.length; right++) {

            int inNum = nums[right];

            // 1. 右边界入窗

            // 在计数加 1 之前，当前的数量就是它能新增的对数

            // 例如：已有 2 个，再来 1 个，新增 2 对。

            totalPairs += cnt.getOrDefault(inNum, 0);

            cnt.merge(inNum, 1, Integer::sum);



            // 2. 收缩左边界

            // 题目要求：总对数 >= k。

            // 我们收缩直到 总对数 < k。

            while (totalPairs >= k) {

                int outNum = nums[left];

                // 先减少计数

                cnt.put(outNum, cnt.get(outNum) - 1);

                // 再减少对数

                // 移除后剩下的数量，就是减少的对数

                // 例如：原有 3 个 (3对)，移除 1 个剩 2 个 (1对)。减少了 2 对。

                // 此时 cnt[outNum] 已经是 2 了。

                totalPairs -= cnt.get(outNum);

                if (cnt.get(outNum) == 0) {

                    cnt.remove(outNum);

                }

                left++;

            }



            // 3. 统计答案

            // 此时 [left, right] 的总对数 < k (不满足)

            // 说明 [left-1, right] 的总对数 >= k (满足)

            // 所以以 right 结尾的合法子数组起始点可以是 0, 1, ..., left-1

            // 共 left 个。

            ans += left;

        }

        return ans;

    }

}
```

```java
        }

        for(int d : diff){

            if(d>0){

                less++;

            }

        }



        long ans = 0 ;

        int left = 0;

        for(char c  : s){

            diff[c-'a']--;

            if(diff[c-'a']==0){

                less-- ;

            }



            while(less == 0){

                char outChar = s[left++];

                if(diff[outChar-'a']==0){

                    less++;

                }

            }

        }
```

### 恰好型滑动窗口
例如，要计算有多少个元素和恰好等于 k 的子数组，可以把问题变成：

计算有多少个元素和 ≥k 的子数组。
计算有多少个元素和 >k，也就是 ≥k+1 的子数组。
答案就是元素和 ≥k 的子数组个数，减去元素和 ≥k+1 的子数组个数。这里把 > 转换成 ≥，从而可以把滑窗逻辑封装成一个函数 solve，然后用 solve(k)−solve(k+1) 计算，无需编写两份滑窗代码。

总结：「恰好」可以拆分成两个「至少」，也就是两个「越长越合法」的滑窗问题。

注：也可以把问题变成 ≤k 减去 ≤k−1，即两个「至多」。可根据题目选择合适的变形方式。

注：也可以把两个滑动窗口合并起来，维护同一个右端点 right 和两个左端点 left1 和 left2，我把这种写法叫做三指针滑动窗口。
#### 题目 1

![题目截图](./figure/Pasted%20image%2020260829050843.png)

**思路**

问：某班有 10 个人至少 20 岁，3 个人至少 21 岁，那么恰好 20 岁的人有多少个？

答：「至少 20 岁」可以分成「恰好 20 岁」和「至少 21 岁」，所以用「至少 20 岁」的人数减去「至少 21 岁」的人数，就是「恰好 20 岁」的人数，即 10−3=7。
根据这个思路，本题等价于如下两个问题：

元素和 ≥goal 的子数组个数。加到答案中。
元素和 >goal 的子数组个数。从答案中减掉。
由于本题 nums[i] 均为非负数，子数组越长，元素和越大，所以是「越长越合法」的计数滑窗问题。一般要写 ans += left。

**解答**

```java
class Solution {

    public int numSubarraysWithSum(int[] nums, int goal) {

        int left1 = 0,left2=0;

        int ans = 0;

        int t1=0,t2=0;

        int cnt1=0,cnt2=0;



        for(int right = 0;right<nums.length;right++){

            cnt1+=nums[right];

            cnt2+=nums[right];

            while(left1<=right && cnt1>=goal){

                cnt1-=nums[left1];

                left1++;

            }

            t1+=left1;

            while(cnt2==goal+1){

                cnt2-=nums[left2];

                left2++;

            }

            t2+=left2;

        }

        return t1-t2;

    }

}
```

```java
                        if(t2.get(c[left2])==0){

                            t2.remove(c[left2]);

                        }

                    }

                }else{

                    cnt2--;

                }

                left2++;

            }

            ans -= left2;

        }

        return ans;

    }



    private boolean isY(char c){
```

#### 题目 4

![题目截图](./figure/Pasted%20image%2020260829055001.png)

**思路**

这道题我犯的一个错误是：当右端点进入窗口时，把对应的键值对自增逻辑搞错了
不管之前里面有没有右端点的值，都应该自增，cntx只是维护窗口里面的不同数字的种类只有当hashmap有新的键值对时，cntx++；

**解答**

```java
class Solution {

    public int subarraysWithKDistinct(int[] nums, int k) {

        int ans = 0;

        int left1 = 0,left2 = 0;

        int cnt1 = 0 , cnt2 = 0;

        Map<Integer,Integer> t1 = new HashMap<>();

        Map<Integer,Integer> t2 = new HashMap<>();



        for(int right = 0;right<nums.length;right++){

            if(!t1.containsKey(nums[right])){

                cnt1 ++ ;

    }

            t1.merge(nums[right],1,Integer::sum);

            while(left1<=right && cnt1>=k){

                t1.merge(nums[left1],-1,Integer::sum);

                if(t1.get(nums[left1])==0){

                    t1.remove(nums[left1]);

                    cnt1--;

            }

                left1++;

            }

            ans += left1;

            if(!t2.containsKey(nums[right])){

                cnt2++ ;

            }

            t2.merge(nums[right],1,Integer::sum);

            while(left2<=right && cnt2>k){

                t2.merge(nums[left2],-1,Integer::sum);

                if(t2.get(nums[left2])==0){

                    t2.remove(nums[left2]);

                    cnt2--;

                }

                left2++;

            }

            ans -= left2;

        }

        return ans;

    }

}
```

#### 题目 5

![题目截图](./figure/Pasted%20image%2020260829061958.png)

**思路**

这道题多出一个维护条件，也就是第二个维护条件，这个时候可以使用函数把要求的满足第1条件的子数组数量区分开，如下代码:calc(nums, k, k, m)是满足第一条件的数量，calc(nums, k+1, k, m)是满足第一条件数量的多余部分，两者相减即可

**解答**

```java
class Solution {

    public long countSubarrays(int[] nums, int k, int m) {

        return calc(nums, k, k, m) - calc(nums, k + 1, k, m);

    }



    private long calc(int[] nums, int distinctLimit, int k, int m) {

        Map<Integer, Integer> cnt = new HashMap<>();

        int geM = 0; // 窗口中的出现次数 >= m 的元素个数

        int left = 0;

        long ans = 0;

        for (int x : nums) {

            // 1. 入

            int c = cnt.merge(x, 1, Integer::sum); // c = ++cnt[x]

            if (c == m) {

                geM++;

            }



            // 2. 出

            while (cnt.size() >= distinctLimit && geM >= k) {

                int out = nums[left];

                c = cnt.get(out);

                if (c == m) {

                    geM--;

                }

                if (c == 1) {

                    cnt.remove(out);

                } else {

                    cnt.put(out, c - 1);

                }

                left++;

            }



            // 3. 更新答案

            ans += left;

        }

        return ans;

    }

}
```
