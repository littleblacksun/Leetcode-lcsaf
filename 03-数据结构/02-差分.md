**思路**

# LeetCode 1094 拼车 —— 简短版思路

## 核心思想：差分数组 + TreeMap 排序

**差分数组**：只记录每站的"人数净变化"，不用逐站模拟。

```
上车站点 from：+num
下车站点 to：  -num
```

## 代码两段的作用

**第一个循环：建差分数组**
```java
d.merge(from, num, Integer::sum);   // from 站 +num
d.merge(to, -num, Integer::sum);    // to 站 -num
```
- `merge` 把同一站点的上下车**累加成净变化值**
- 结束后 `TreeMap` 里是 `{站点: 净变化}`，且**按站点自动排序**

**第二个循环：前缀和还原实际人数**
```java
int s = 0;
for(int v : d.values()){
    s += v;              // s = 当前车上人数
    if(s > capacity) return false;
}
```
- 按站点顺序累加变化量，得到每站实际乘客数
- 任意时刻超载即返回 `false`

## 为什么用 TreeMap

第二个循环**必须按站点顺序**求前缀和，`TreeMap` 保证 key 有序，`HashMap` 做不到。

## 复杂度

- 时间：O(n log n)
- 空间：O(n)

> **一句话**：起点 `+num`、终点 `-num` 建差分数组，按站点顺序求前缀和还原实际人数，判断是否超载。

**解答**

```java
class Solution {

    public boolean carPooling(int[][] trips, int capacity) {

        TreeMap<Integer,Integer> d = new TreeMap<>();

        for(int[] t : trips){

            int num = t[0], from = t[1],to = t[2];

            d.merge(from,num,Integer::sum);

            d.merge(to,-num,Integer::sum);

        }



        int s = 0;

        for(int v : d.values()){

            s += v;

            if(s>capacity){

                return false;

            }

        }

        return true;

    }

}
```

**思路**

这是一份为你整理的**简短版解题思路**，适合用来快速复习或写在题解开头：

### 💡 核心思路：差分 + 扫描线

**1. 转化问题**
题目要求统计被任意车辆覆盖的**整数点**总数。可以将每辆车看作一个区间 `[start, end]`，问题转化为：**求所有区间的并集覆盖了多少个整数点**。

**2. 差分思想**
利用差分数组记录覆盖状态的变化：
*   在起点 `start` 处：覆盖数 `+1`
*   在终点后一位 `end + 1` 处：覆盖数 `-1`

**3. 处理稀疏坐标**
由于坐标范围可能很大（如 \(10^9\)），无法直接开数组。使用**哈希表（或 TreeMap）**记录变化点，并对所有变化点的坐标进行**排序**。

**4. 扫描累加**
按坐标从小到大遍历变化点，维护一个变量 `current_coverage`（当前覆盖数）：
*   累加当前点的差分值。
*   如果 `current_coverage > 0`，说明从当前点到下一个变化点之间的所有整数点都被覆盖。
*   累加区间长度：`next_pos - current_pos`。

**复杂度**：时间 \(O(N \log N)\)（主要消耗在排序），空间 \(O(N)\)。

---

**解答**

```java
import java.util.*;



class Solution {

    public int numberOfPoints(List<List<Integer>> nums) {

        // 使用 TreeMap 存储差分，key 自动按升序排列

        TreeMap<Integer, Integer> diff = new TreeMap<>();

        for (List<Integer> car : nums) {

            int start = car.get(0);

            int end = car.get(1);

            // 在 start 处 +1

            diff.put(start, diff.getOrDefault(start, 0) + 1);

            // 在 end + 1 处 -1

            diff.put(end + 1, diff.getOrDefault(end + 1, 0) - 1);

        }

        int ans = 0;

        int currentCoverage = 0;

        Integer prevPos = null;

        // 遍历 TreeMap，key 已经是升序的

        for (Map.Entry<Integer, Integer> entry : diff.entrySet()) {

            int pos = entry.getKey();

            // 如果前一个位置存在，并且当前覆盖数 > 0，则累加区间长度

            if (prevPos != null && currentCoverage > 0) {

                ans += pos - prevPos;

            }

            // 更新当前覆盖数

            currentCoverage += entry.getValue();

            // 记录当前位置，供下一次循环使用

            prevPos = pos;

        }

        return ans;

    }

}
```

![题目截图](./figure/Pasted%20image%2020260910141319.png)

**思路**

### 💡 核心思路：差分 + 扫描线

**1. 问题转化**  
题目要求判断 `[left, right]` 内是否每个整数都被 `ranges` 中至少一个区间覆盖。等价于：**在 `[left, right]` 范围内，任意位置的覆盖数都必须 > 0**。

**2. 差分思想**  
对每个区间 `[start, end]`，用差分记录覆盖数的变化：

- `start` 处：覆盖数 `+1`

- `end + 1` 处：覆盖数 `-1`


**3. 处理稀疏坐标**  
用 `TreeMap` 存储差分点（自动按坐标升序排列）。为了让扫描完整覆盖 `[left, right]`，**加入两个哨兵**：

- `putIfAbsent(left, 0)` —— 保证从左端点开始扫描

- `putIfAbsent(right + 1, 0)` —— 保证扫描到右端点结束


**4. 扫描判断**  
按坐标从小到大遍历 `TreeMap`，维护两个变量：

- `coverage`：当前段的覆盖数（用**旧值**判断 `[prevPos, pos)`）

- `prevPos`：上一个关键点坐标


对每一段 `[prevPos, pos)`：

- 与 `[left, right]` 求交集 `[segStart, segEnd]`

- 若 `segStart <= segEnd`（有交集）且 `coverage == 0`（未覆盖）→ 返回 `false`


遍历结束返回 `true`。

**复杂度**：时间 O(Nlog⁡N)，空间 O(N)。
**解答**

```java
class Solution {

    public boolean isCovered(int[][] ranges, int left, int right) {

        TreeMap<Integer, Integer> diff = new TreeMap<>();

        // 1. 构建差分表

        for (int[] range : ranges) {

            diff.put(range[0], diff.getOrDefault(range[0], 0) + 1);

            diff.put(range[1] + 1, diff.getOrDefault(range[1] + 1, 0) - 1);

        }

        // 🔑 2. 加入两个哨兵，保证 [left, right] 被完整扫描

        diff.putIfAbsent(left, 0);        // 左哨兵：确保从 left 开始扫描

        diff.putIfAbsent(right + 1, 0);   // 右哨兵：确保扫描到 right 结束

        int coverage = 0;

        Integer prevPos = null;

        // 3. 扫描关键点

        for (Map.Entry<Integer, Integer> entry : diff.entrySet()) {

            int pos = entry.getKey();

            // 检查 [prevPos, pos) 这段区间

            if (prevPos != null) {

                int segStart = Math.max(prevPos, left);

                int segEnd = Math.min(pos - 1, right);

                // 如果这段与 [left, right] 有交集，且覆盖数为 0，则失败

                if (segStart <= segEnd && coverage == 0) {

                    return false;

                }

            }

            // 更新覆盖数和前一个位置

            coverage += entry.getValue();

            prevPos = pos;

        }

        return true;

    }

}
```

**思路**

针对这道题，使用**差分数组（Difference Array）**的简短思路总结如下：

**核心思想：**
将“区间内人数累加”的问题，转化为“在区间起点 +1，终点后一位 -1”的端点变化问题。

**具体步骤：**
1. **打差分标记**：遍历每个人的 `[birth, death]`。
   * 在 `birth` 年份：人数变化量 `+1`（代表有人出生）。
   * 在 `death` 年份：人数变化量 `-1`（因为死亡当年不计入，相当于在 `death` 这一年区间结束）。
2. **按年份求前缀和**：将所有年份按从小到大排序，依次累加变化量（`coverage += diff`），就能还原出**每一年真实的人口数**。
3. **找最早峰值**：在累加过程中，记录出现过的最大人口数（`ans`）。由于是从小到大遍历年份，**第一次**达到最大人口数的年份，就是“人口最多且最早”的年份（`early`）。
4.  // 注意：如果 coverage == ans，因为 TreeMap 是按 key 升序遍历的，
    // 我们遇到的第一个达到 ans 的年份一定是最早的，所以不需要额外处理相等的情况。
**解答**

```java
class Solution {

    public int maximumPopulation(int[][] logs) {

        TreeMap<Integer,Integer> diff = new TreeMap<>();

        for(int[] log : logs){

            //按照寻常的差分处理逻辑，应该log[1]-1,但是本题x 在闭区间 [birthi, deathi - 1]

            diff.put(log[0],diff.getOrDefault(log[0],0)+1);

            diff.put(log[1],diff.getOrDefault(log[1],0)-1);

        }



        int early = Integer.MAX_VALUE ;

        int ans = 0;

        int coverage = 0;

        Integer prevPos = null;



        for(var entry : diff.entrySet()){

            int pos =  entry.getKey();

            coverage+=entry.getValue();//// 1. 先累加差分，得到当前年份 pos 的人口数



            // // 2. 比较当前年份的人口数和历史最大值

            if(coverage>ans){

                ans = coverage;

                early = pos;

            }

            prevPos = pos;

        }

        return early==Integer.MAX_VALUE?0:early;

    }

}
```

#### 题目 6

![题目截图](./figure/Pasted%20image%2020260910170814.png)

**思路**
	没问题，这道题（1109. 航班预订统计）是一道非常经典的**差分数组**入门题。咱们抛开复杂的代码，用最简单的大白话给你梳理一下这道题的解题思路。

---

### 💡 核心痛点：为什么不能硬算？

题目给了很多条预订记录，比如“从第 1 个航班到第 2 个航班，订 10 个座”。
如果你老老实实写两层循环，外层遍历记录，内层把 `1` 到 `2` 航班的座位数都加上 `10`。
一旦数据量变大（比如有 10 万条记录，每条都横跨 10 万个航班），电脑就会算得超级慢（时间复杂度 \(O(m \times n)\)），直接超时。

**根本原因**：每次预订，都要去修改区间内所有航班的值，重复劳动太多了。

---

### 🚀 破局思路：差分数组（记账本）

差分数组的核心思想就是：**我不去挨个修改航班了，我只在“账本”上记一笔，最后统一结算。**

**第一步：怎么记账？（区间修改 \(O(1)\)）**
对于每一条预订记录 `[first, last, seats]`，我们只需要在差分数组 `diff` 上做两个动作：
1. 在 `first` 的位置：`diff[first] += seats` （表示从这站开始，车上多了 seats 个人）
2. 在 `last + 1` 的位置：`diff[last + 1] -= seats` （表示过了这站，下一站开始，车上少了 seats 个人）

*注意：这就是差分的精髓，不管区间多长，我只改两个点，时间复杂度降为 \(O(1)\)。*

**第二步：怎么结算？（求前缀和 \(O(n)\)）**
记完账后，我们从头到尾遍历航班 `1` 到 `n`：
* 用一个变量 `currentSeats` 累加 `diff` 数组的值：`currentSeats += diff[i]`。
* 这个 `currentSeats` 就是当前第 `i` 个航班真实的座位总数。
* 把它填入结果数组 `ans[i - 1]` 中。

**总时间复杂度**：\(O(m + n)\)，非常快！

---

### ⚠️ 避坑指南（写代码时容易错的点）

1. **数组开多大？**
   差分数组要开 `n + 2` 的大小。因为如果有一条记录是 `[2, n, 20]`，那么 `last + 1` 就是 `n + 1`，如果只开到 `n`，就会数组越界。
2. **下标怎么对应？**
   题目给的航班编号是 `1` 到 `n`，而我们返回的数组下标是 `0` 到 `n-1`。所以最后填结果时，是 `ans[i - 1] = currentSeats`。
3. **不要用 TreeMap！**
   虽然用 Map 也能记录差分，但下标是连续的，直接用 `int[]` 数组是最快、最不容易出错的。Map 会有额外的对象开销和查找时间。

---

### 📝 一句话总结

**“左端点加，右端点+1 减，最后从头到尾求前缀和。”**
	这就是差分数组解决区间批量修改问题的万能公式。
**解答**
```java
class Solution {

    public int[] corpFlightBookings(int[][] bookings, int n) {

        TreeMap<Integer,Integer> diff = new TreeMap<>();

        for(int[] book : bookings){

            diff.put(book[0],diff.getOrDefault(book[0],0)+book[2]);

            diff.put(book[1]+1,diff.getOrDefault(book[1]+1,0)-book[2]);

        }

        int[] ans = new int[n];

        int prevPos=0;

        int i = 0;

        int cnt = 0;

        // 核心优化：按照航班号 1 到 n 逐个还原

        for (int flight = 1; flight <= n; flight++) {

            // 如果当前航班号在 diff 中有记录，就更新 cnt

            if (diff.containsKey(flight)) {

                cnt += diff.get(flight);

            }

            // 把当前累计的座位数填入结果数组

            // flight 从 1 开始，ans 下标从 0 开始，所以是 flight - 1

            ans[flight - 1] = cnt;

        }

        return ans;

    }

}
```

#### 题目 7

![题目截图](./figure/Pasted%20image%2020260910175823.png)

**思路**
没问题，咱们把这道题（3964. 照亮道路的最少灯泡数）的解法，提炼成一份**最核心、最好记**的短思路，方便你以后复习。

---

### 💡 核心思想：贪心 + 差分（边走边记账）

**一句话总结**：从左到右走，遇到黑的就装灯，用差分数组记录灯光什么时候熄灭。

---

### 🚶 解题三步走

**第一步：预处理原灯泡（记初始账）**
遍历原数组 `lights`，把每个已有灯泡的照亮范围 `[i-v, i+v]` 记录到差分数组 `diff` 里。
* 左边界：`diff[max(i-v, 0)] += 1`
* 右边界：`diff[min(i+v+1, n)] -= 1`（注意右边界是开区间，要 +1）

**第二步：贪心遍历（边走边决策）**
从左到右遍历每个位置 `i`，用 `sumD` 维护当前位置的真实光照强度。
* `sumD += diff[i]`（结算当前位置的光照变化）
* **如果 `sumD == 0`（当前位置没光）**：
  * 必须装灯！`ans++`
  * 在 `i+1` 处装灯，照亮 `[i, i+2]`。
  * 当前亮了：`sumD += 1`
  * 记录这盏灯在 `i+3` 处熄灭：`diff[min(i+3, n)] -= 1`

**第三步：返回答案**
遍历结束，`ans` 就是最少额外灯泡数。

---

### ⚠️ 三个关键细节（避坑指南）

1. **为什么用差分？**
   因为一个灯泡照亮的是一个**区间**。用差分可以把“区间修改”变成 \(O(1)\) 的“端点记账”，避免每次装灯都去循环修改后面所有位置。

2. **为什么右边界是 `+1` 后减 1？**
   差分数组的规则是：区间 `[L, R]` 加 1，等价于 `diff[L] += 1` 且 `diff[R+1] -= 1`。因为光照是**包含右边界**的，所以要在 `R+1` 处减 1，表示“过了这个点就照不到了”。

3. **`sumD` 为什么能代替 `diff[i]` 的累加？**
   `sumD` 本质上就是差分数组的前缀和。你巧妙地把 `diff[i] += 1` 直接合并到了 `sumD += 1` 里，省去了一次数组写入，非常高效。

---

### 📝 复杂度分析
* **时间复杂度**：\(O(n)\)，只需遍历两次数组。
* **空间复杂度**：\(O(n)\)，需要一个差分数组 `diff`。

---

### 🎯 一句话记忆口诀
**“原灯先记账，黑处就装灯，光照到 i+3，账本减一清。”**
**解答**
```java
class Solution {

    public int minLights(int[] lights) {

        int n = lights.length;

        int[] diff = new int[n+1];

        for(int i = 0 ; i<n;i++){

            int v = lights[i];

            if(v>0){

                diff[Math.max(i-v,0)] += 1;

                diff[Math.min(n,i+v+1)] -=1;

            }


		}


		int ans = 0;

        int sumD = 0;

        for(int i = 0; i<n;i++){

            sumD+=diff[i];

            if(sumD==0){

                ans+=1;

                sumD+=1;

                diff[Math.min(i+3,n)] -=1;

            }

        }

        return ans;

    }

}
```

#### 题目 8

![题目截图](./figure/Pasted%20image%2020260911131229.png)

**思路**
这道题的核心思路可以总结为以下三步：

**1. 转化问题（差分思想）**
*   题目要求数组最终**非递减**，等价于要求其**差分数组 `diff`（从下标 1 开始）全部 `>= 0`**。
*   对原数组区间 `[l, r]` 增加 `x`，等价于在差分数组上：`diff[l] += x`，`diff[r+1] -= x`。

**2. 贪心策略（寻找最优操作）**
*   对于差分数组中任意一个负数 `diff[i]`（`i >= 1`），必须通过以 `i` 为左端点的操作来增加它。
*   为了让操作代价最小且不引入新的负数，**最优做法是让右端点 `r` 一直延伸到数组末尾（即 `r = n - 1`）。这样 `r+1` 越界，就不会在别处产生 `-x` 的副作用。**

**3. 得出公式（累加绝对值）**
*   针对每个负数 `diff[i]`，单独执行一次操作，增加的 `x` 恰好等于 `-diff[i]`。
*   最终的最小累计值，就是**所有负的差分值（从下标 1 开始）的绝对值之和**。

**一句话总结：**
遍历数组计算相邻差值，把所有“下降”（即后一个数小于前一个数）的差值累加起来，就是答案。
**解答**
```java
class Solution {

    public long minOperations(int[] nums) {

        int n = nums.length;

        int[] diff = new int[n];

        diff[0] = nums[0];

        for(int i = 1;i<n;i++){

            diff[i] = nums[i] - nums[i-1];

        }

        long ans = 0;

        for(int j = 0; j<n;j++){

            if(diff[j]<0){

                ans+=(-diff[j]);

            }

        }

        return ans;

    }

}
```

**思路**
只需要使用差分数组统计在哪些位置发生了变化即可，然后遍历循环的时候，使用一个变量去维护变化量，然后进行相关操作即可
**解答**
```java
class Solution {

    public String shiftingLetters(String s, int[][] shifts) {

        char[] c = s.toCharArray();

        int n = c.length;

        int[] diff = new int[n+1];

        for(int[] x :shifts){

            int a = x[0];

            int b = x[1];

            int l = x[2]==0?-1:1;

            diff[a]+=l;

            diff[b+1]-=l;

        }

        int y = 0;

        for(int j = 0 ; j<n;j++){

            y+=diff[j];

            int offset = c[j] - 'a';

            int newoffset = Math.floorMod(offset+y,26);

            c[j] = (char)('a'+newoffset);

        }

        return new String(c);

    }

}
```
