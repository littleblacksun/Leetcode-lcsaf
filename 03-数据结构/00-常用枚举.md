# 枚举右 维护左
对于 双变量问题，例如两数之和 a i+a j=t，可以枚举右边的 a j，转化成 单变量问题，也就是在 a j左边查找是否有 a i=t−a j
​
 ，这可以用哈希表维护。

我把这个技巧叫做 枚举右，维护左。

#### 题目 1

![题目截图](./figure/Pasted%20image%2020260830144541.png)

**思路**

使用hashmap进行维护即可

**解答**

```java
class Solution {

    public int[] twoSum(int[] nums, int target) {

        Map<Integer,Integer> c = new HashMap<>();

        for(int i = 0; i<nums.length;i++){

            int x = nums[i];

            if(c.containsKey(target-x)){

                return new int[]{c.get(target-x),i};

            }

            c.put(x,i);

        }

        return new int[0];

    }

}
```

#### 题目 2

![题目截图](./figure/Pasted%20image%2020260830145233.png)

**思路**

HashMap

**解答**

```java
class Solution {

    public int numIdenticalPairs(int[] nums) {

        Map<Integer,Integer> idx = new HashMap<>();

        int ans = 0;

        for(int i = 0; i<nums.length;i++){

            int x = nums[i];

            if(!idx.containsKey(x)){

                idx.merge(x,1,Integer::sum);

            }

            else{

                ans += idx.get(x);

                idx.merge(x,1,Integer::sum);

            }

        }

        return ans;

    }

}
```

#### 题目 3

![题目截图](./figure/Pasted%20image%2020260830150106.png)

**思路**

这个题目由于不涉及到键值对，直接用hashSet即可

**解答**

```java
class Solution { public int findMaxK(int[] nums) { int ans = -1; var s = new HashSet<Integer>(); for (int x : nums) { if (s.contains(-x)) ans = Math.max(ans, Math.abs(x)); s.add(x); } return ans; } }
```

#### 题目 4

![题目截图](./figure/Pasted%20image%2020260830151055.png)

**思路**

easy

**解答**

```java
class Solution {

    public int maxProfit(int[] prices) {

        int ans = 0;

        int di = prices[0];

        for(int i = 1;i<prices.length;i++){

            if(prices[i] >= di){

                ans = Math.max(ans,prices[i]-di);

            }

            else{

                di = prices[i];

            }

        }

        return ans;

    }

}
```

#### 题目 5

![题目截图](./figure/Pasted%20image%2020260830151743.png)

**思路**

返回值判断条件和上题不同

**解答**

```java
class Solution {

    public int maximumDifference(int[] nums) {

        int ans = -1;

        int minX = nums[0];

        for(int x=1;x<nums.length; x++){

            ans = Math.max(ans,(nums[x]-minX));

            minX = Math.min(minX,nums[x]);

        }

        return ans>0?ans:-1;

    }

}
```

#### 题目 6

![题目截图](./figure/Pasted%20image%2020260830152455.png)

**思路**

这道题，解题时思路陷入到了，没有考虑到，两个整数可能来自于同一个数组，**正确解题思路：** 应该遍历每一个数组，然后获取到当前数组的最大值和最小值，然后同以前见过的数组最大值和最小值进行比较，更新最大值和最小值，这样子可以确保两个整数来自不同的数组

**解答**

```java
class Solution {

    public int maxDistance(List<List<Integer>> arrays) {

        // 用第一个数组的最小值和最大值初始化

        int minVal = arrays.get(0).get(0);

        int maxVal = arrays.get(0).get(arrays.get(0).size() - 1);

        int ans = 0;

        // 从第二个数组开始遍历 (索引 1)

        for (int i = 1; i < arrays.size(); i++) {

            List<Integer> curr = arrays.get(i);

            int currMin = curr.get(0);

            int currMax = curr.get(curr.size() - 1);

            // 核心逻辑：

            // 1. 用当前数组的最大值 - 之前的最小值

            // 2. 用之前的最大值 - 当前数组的最小值

            // 取两者的最大值来更新答案

            ans = Math.max(ans, Math.max(currMax - minVal, maxVal - currMin));

            // 更新全局的最小值和最大值，供下一次循环使用

            minVal = Math.min(minVal, currMin);

            maxVal = Math.max(maxVal, currMax);

        }

        return ans;

    }

}
```
