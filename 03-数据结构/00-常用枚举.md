# 枚举右 维护左
对于 双变量问题，例如两数之和 a i+a j=t，可以枚举右边的 a j，转化成 单变量问题，也就是在 a j左边查找是否有 a i=t−a j
​
 ，这可以用哈希表维护。

我把这个技巧叫做 枚举右，维护左。

#### 题目 1

![题目截图](./figure/Pasted%20image%2020260830144541.png)

**思路**

使用hashmap进行维护即可

**解答**

```java
class Solution {

    public int[] twoSum(int[] nums, int target) {

        Map<Integer,Integer> c = new HashMap<>();

        for(int i = 0; i<nums.length;i++){

            int x = nums[i];

            if(c.containsKey(target-x)){

                return new int[]{c.get(target-x),i};

            }

            c.put(x,i);

        }

        return new int[0];

    }

}
```

```java
class Solution {

    public int numIdenticalPairs(int[] nums) {

        Map<Integer,Integer> idx = new HashMap<>();

        int ans = 0;

        for(int i = 0; i<nums.length;i++){

            int x = nums[i];

            if(!idx.containsKey(x)){

                idx.merge(x,1,Integer::sum);

                ans += idx.get(x);

                idx.merge(x,1,Integer::sum);

            }

        }

        return ans;

    }

}
```

#### 题目 6

![题目截图](./figure/Pasted%20image%2020260830152455.png)

**思路**

这道题，解题时思路陷入到了，没有考虑到，两个整数可能来自于同一个数组，**正确解题思路：** 应该遍历每一个数组，然后获取到当前数组的最大值和最小值，然后同以前见过的数组最大值和最小值进行比较，更新最大值和最小值，这样子可以确保两个整数来自不同的数组

**解答**

```java
class Solution {

    public int maxDistance(List<List<Integer>> arrays) {

        // 用第一个数组的最小值和最大值初始化

        int minVal = arrays.get(0).get(0);

        int maxVal = arrays.get(0).get(arrays.get(0).size() - 1);

        int ans = 0;

        // 从第二个数组开始遍历 (索引 1)

        for (int i = 1; i < arrays.size(); i++) {

            List<Integer> curr = arrays.get(i);

            int currMin = curr.get(0);

            int currMax = curr.get(curr.size() - 1);

            // 核心逻辑：

            // 1. 用当前数组的最大值 - 之前的最小值

            // 2. 用之前的最大值 - 当前数组的最小值

            // 取两者的最大值来更新答案

            ans = Math.max(ans, Math.max(currMax - minVal, maxVal - currMin));

            // 更新全局的最小值和最大值，供下一次循环使用

            minVal = Math.min(minVal, currMin);

            maxVal = Math.max(maxVal, currMax);

        }

        return ans;

    }

}
```

#### 题目 7

![题目截图](./figure/Pasted%20image%2020260831013425.png)

**思路**

这道题用两个变量去维护：当遍历到nums[x]时，离自己最近的1或者2的下标

**解答**

```java
class Solution {

    public int minAbsoluteDifference(int[] nums) {

        // 初始化答案为一个大数，用于后续取 min

        int ans = Integer.MAX_VALUE;

        // 记录最近一次出现 1 和 2 的下标

        // 初始化为一个很小的负数，确保第一次计算出的 abs 差值很大

        int last1 = -1000000;

        int last2 = -1000000;

        for (int i = 0; i < nums.length; i++) {

            if (nums[i] == 1) {

                // 当前是 1，尝试用它和最近的一个 2 计算差值

                ans = Math.min(ans, Math.abs(i - last2));

                // 更新最近一次 1 的下标

                last1 = i;

            } else if (nums[i] == 2) {

                // 当前是 2，尝试用它和最近的一个 1 计算差值

                ans = Math.min(ans, Math.abs(i - last1));

                // 更新最近一次 2 的下标

                last2 = i;

            }

        }

        // 如果 ans 没有被更新过（或者更新后的值依然大于数组最大可能长度），说明不存在有效对

        if (ans > nums.length) {

            return -1;

        }

        return ans;

    }

}
```

#### 题目 8

![题目截图](./figure/Pasted%20image%2020260831014049.png)

**思路**

这道题换一个想法，他的数组范围1-10e9，那么数位和加起来最多是9个9相加，也就是81，那么可以使用一个数组来维护他。枚举右，维护左，读取左边是否有满足条件的

**解答**

```java
class Solution {

    public int maximumSum(int[] nums) {

        int ans = -1;

        int[] mx = new int[82]; // 至多 9 个 9 相加

        Arrays.fill(mx, Integer.MIN_VALUE);

        for (int num : nums) { // 枚举 num = nums[j]

            int s = 0; // num 的数位和

            for (int x = num; x > 0; x /= 10) { // 枚举 num 的每个数位

                s += x % 10;

            }

            ans = Math.max(ans, mx[s] + num); // 左边找一个数位和也为 s 的最大的 nums[i]

            mx[s] = Math.max(mx[s], num); // 维护数位和等于 s 的最大元素

        }

        return ans;

    }

}
```

#### 题目 10

![题目截图](./figure/Pasted%20image%2020260831020236.png)

**思路**

例如 [1,2] 和 [2,1] 这两个骨牌，我们可以旋转 [2,1] 得到 [1,2]，所以 [1,2] 和 [2,1] 本质上是相等的。

对于每个 dominoes[i]=[a,b]，如果 a>b，我们就交换 a 和 b，从而保证 a≤b
那么只需要维护一个二维数组，用数组值来确定某一个骨牌出现了多少次，然后ans+=（超过2次的骨牌）
**解答**

```java
class Solution {

    public int numEquivDominoPairs(int[][] dominoes) {

        int ans = 0;

        int[][] cnt =new int[10][10];

        for(int[] d: dominoes){

            int a = Math.min(d[0],d[1]);

            int b = Math.max(d[0],d[1]);

            ans += cnt[a][b]++; //先更新答案，在把对数加进来

        }

        return ans;

    }

}
```

#### 题目 11

![题目截图](./figure/Pasted%20image%2020260831021222.png)

**思路**

这道题同样可以如同两数之和一样，遍历到num是，去寻找hashmap中是否有target-num
不过这里多了枚举右，维护左，那么在枚举右的时候，要求看看左边是否还有target-num？有的话正好配对 ，没有的话，把num加入到hashmap中，等待他的”另一半“

**解答**

```java
class Solution {

    /**

     * 找出数组中两数之和为指定值的所有整数对。

     * 核心限制：一个数只能属于一个数对（即用过一次就不能再用）。

     *

     * @param nums   输入的整数数组

     * @param target 目标和

     * @return       所有满足条件的数对列表

     */

    public List<List<Integer>> pairSums(int[] nums, int target) {

        // 1. 创建一个哈希表，用于记录"单身等待配对"的数字及其剩余可用次数

        // Key: 数组中的数字

        // Value: 该数字当前还没被配对的剩余个数

        Map<Integer, Integer> map = new HashMap<>();

        // 2. 创建结果列表，用于存放最终找到的所有数对

        List<List<Integer>> ans = new ArrayList<>();

        // 3. 遍历数组中的每一个数字

        for (int num : nums) {

            // 计算当前数字 num 想要凑成 target 所需要的"另一半"

            int complement = target - num;

            // 4. 去哈希表中查找"另一半"的库存是否大于 0

            // getOrDefault 表示如果 map 中没有这个 key，就默认返回 0

            if (map.getOrDefault(complement, 0) > 0) {

                // 【情况 A：配对成功】

                // 说明在之前的遍历中，有剩下的 complement 可以和当前的 num 凑成一对

                // 将这一对 [complement, num] 加入最终结果

                ans.add(Arrays.asList(complement, num));

                // 【关键步骤】消耗库存！

                // 因为题目要求"一个数只能属于一个数对"，

                // 既然 complement 已经被当前的 num 用掉了，它的可用次数必须减 1

                map.put(complement, map.get(complement) - 1);

            } else {

                // 【情况 B：暂时单身】

                // 说明之前没有多余的 complement 可以和当前的 num 配对

                // 只能把当前的 num 存进哈希表里"排队等待"， hoping 后面能有数字来和它配对

                // merge 方法解释：

                // 如果 map 中还没有 num，则存入 (num, 1)

                // 如果 map 中已经有 num，则将原来的 value 与 1 相加 (Integer::sum)，即库存 + 1

                map.merge(num, 1, Integer::sum);

            }

        }

        // 5. 遍历结束，返回所有找到的数对

        return ans;

    }

}
```

#### 题目 12

![题目截图](./figure/Pasted%20image%2020260831022302.png)

**思路**

map.getOrDefault(nums[i], 0) > 0` 这个判断逻辑有漏洞
你用 `> 0` 来判断这个数字之前是否出现过。这在大多数情况下没问题，**但如果数字之前出现在下标 0 的位置，就会出 Bug！**

- **漏洞场景**：假设 `nums[0] = 5`。你把 `(5, 0)` 存入了 map。
- 当你后面再次遇到 `5` 时（比如下标 `i = 2`），你去查 `map.getOrDefault(5, 0)`，拿到的是 `0`。
- 你的判断条件 `0 > 0` 结果是 `false`！
- **后果**：你的代码会认为 `5` 之前**没有出现过**，从而跳过了 `if` 里面的判断，直接执行 `map.put(5, 2)` 覆盖了旧值。这就导致你漏掉了本来可能符合条件的配对。
**解答**

```java
class Solution {

    public boolean containsNearbyDuplicate(int[] nums, int k) {

        Map<Integer,Integer> map = new HashMap<>();



        for(int i = 0 ; i<nums.length;i++){

            if(map.containsKey(nums[i]) && i-map.get(nums[i])<=k){

                return true;

            }

            map.put(nums[i],i);

        }

        return false;

    }

}
```

#### 题目 15

![题目截图](./figure/Pasted%20image%2020260831025459.png)

**思路**

数位上面只有0-9，所以用一个大小为10的数组进行维护即可，不过要约束ans的更新条件，只有当某一个数位上面已经有值的情况下，才去更新ans，第一次的话，新增进去即可

**解答**

```java
class Solution {

    public int maxSum(int[] nums) {

        int ans = -1;

        int[] csgo = new int[10];

        Arrays.fill(csgo,-1);

        for(int x = 0; x<nums.length;x++){

            int i = kMax(nums[x]);

            if(csgo[i]!=-1){

                ans = Math.max(ans,nums[x]+csgo[i]);

            }

            csgo[i] = Math.max(csgo[i],nums[x]);

        }

        return ans;

    }

    private int kMax(int x){

        int ans = 0;

        for(;x>0;x=x/10){

            int b = x % 10;

            ans = Math.max(b,ans);

        }

        return ans;

    }

}
```

#### 题目 16

![题目截图](./figure/Pasted%20image%2020260831103912.png)

**思路**

同样是枚举右，维护左，不过得转变一下思路
首先，统计每一行的点的个数，如果这一行有 c 个点，那么从 c 个点中选 2 个点，有 c(c−1)/2种选法，可以组成一条水平边，即梯形的顶边或底边。枚举每一行，设这一行有 k= c(c−1)/2条水平边，那么另外一条边就是之前遍历过的行的边数 s。根据乘法原理，之前遍历过的行与这一行，一共可以组成s⋅k个水平梯形，加入答案。
**解答**

```java
class Solution {

    private static final int MOD = 1_000_000_007;



    public int countTrapezoids(int[][] points) {

        Map<Integer, Integer> cnt = HashMap.newHashMap(points.length); // 预分配空间

        for (int[] p : points) {

            cnt.merge(p[1], 1, Integer::sum); // 统计每一行（水平线）有多少个点

        }



        long ans = 0, s = 0;

        for (int c : cnt.values()) {

            long k = (long) c * (c - 1) / 2;

            ans += s * k;

            s += k;

        }

        return (int) (ans % MOD);

    }

}
```

#### 题目 17

![题目截图](./figure/Pasted%20image%2020260831160444.png)

**思路**

这道题重点在于把全部的字符串首位都归一化到a，然后计算后面的字符相对于第一个字符的偏移量是多少，然后用hashmap进行维护
这是一份简短的解题思路总结：

**核心思想：相对位移归一化**

1. **相似的本质**：两个字符串相似，意味着它们对应位置字符的**相对差值**完全相同（整体平移不改变相对结构）。
2. **构造标准键 (Key)**：为了用 HashMap 统计，需将每个字符串转换为唯一的“标准形式”。
    - 以首字符 `base` 为基准，计算每个字符相对于 `base` 的偏移量：`(t[i] - base + 26) % 26`。
    - **减 `base`**：消除整体移位差异，使 `"abc"` 和 `"xyz"` 映射为相同的序列 `(0, 1, 2)`。
    - **`+26) % 26`**：处理负数回绕（如 `'a'-'z'`），确保结果在 `[0, 25]` 范围内。
3. **统计对数**：遍历数组，将转换后的标准字符串作为 Key 存入 Map。每遇到一个已存在的 Key，说明找到了若干对相似字符串，累加其当前计数即可。
**解答**

```java
class Solution {

    public long countPairs(String[] words) {

        Map<String,Integer> cnt = new HashMap<>();

        long ans = 0;

        for(String s : words){

            char[] t = s.toCharArray();

            char base = t[0];

            for(int i = 0; i<t.length;i++){

                t[i] = (char)((t[i]-base+26)%26); //保证结果在[0-25]

            }

            s = new String(t);

            int c = cnt.getOrDefault(s,0);

            ans += c;

            cnt.put(s,c+1);

        }

        return ans;

    }

}
```

#### 题目 18

![题目截图](./figure/Pasted%20image%2020260831162504.png)

**思路**

分析
设异常值为 x，元素和为 y，那么其余 n−2 个数的和也是 y，所以 x+2y 就是整个 nums 数组的元素和 total，即
x+2y=total
也就是说，问题相当于从 nums 中选出两个（下标不同的）数 x 和 y，满足 x+2y 等于一个定值。你需要计算 x 的最大值是多少。

这是一份针对该代码的简短解题思路总结：

**核心思想：枚举异常值 + 哈希表验证**

1. **数学推导**：

    - 设数组总和为 `total`，假设当前元素 `x` 为**异常值**。

    - 根据定义：$S = \text{特殊数字之和}$，故剩余元素总和 $\text{total} - x = S + S = 2S$。

2. **哈希表动态维护（关键步骤）**：

    - **预处理**：统计所有数字频次 `cnt` 及总和 `total`。
    - **枚举与剔除 (`merge(x, -1)`)**：遍历每个 `x` 假设为异常值时，必须先将其从 `cnt` 中**暂时移除**。这是为了满足题目“下标必须不同”的要求，防止 `x` 自身被误判为所需的和值 $S$。
    - **验证**：检查 `(total-x)` 是否为偶数，且 `cnt` 中是否存在 $(total-x)/2$。若满足，则 `x` 是合法异常值，更新最大值。
    - **恢复现场 (`merge(x, 1)`)**：验证结束后，将 `x` 加回 `cnt`，确保下一次循环时哈希表仍代表完整数组的统计信息。
3. **结果**：遍历完成后，返回记录的最大合法异常值即可。

**解答**

```java
class Solution {

    public int getLargestOutlier(int[] nums) {

        Map<Integer,Integer> cnt = new HashMap<>();

        int total = 0;

        for(int x : nums){

            cnt.merge(x,1,Integer::sum);

            total+=x;

        }



        int ans = Integer.MIN_VALUE;

        for(int x : nums){

            cnt.merge(x,-1,Integer::sum);

            if((total-x)%2==0 && cnt.getOrDefault((total-x)/2,0)>0){

                ans = Math.max(ans,x);

            }

            cnt.merge(x,1,Integer::sum);

        }

        return ans;

    }



}
```

#### 题目 19

![题目截图](./figure/Pasted%20image%2020260831163953.png)

**思路**

#### 1. 识别陷阱：放弃“双向对称”思维

- **直觉误区**：很多人会认为 `A` 翻转等于 `B`，那么 `B` 翻转一定等于 `A`。于是想着把原值存进 Map，后面查翻转值。
- **致命陷阱**：题目规定了**忽略前导零**（如 `120 -> 21`，但 `21 -> 12`）。这意味着**翻转操作是不可逆的**。
- **破局点**：必须严格按照题目定义的单向公式 `reverse(nums[i]) == nums[j]` （其中 `i < j`）来设计算法，绝不能反过来查。

#### 2. 转换视角：从“我找别人”变成“别人找我”

因为我们是从左到右遍历数组（`i` 从小到大），当我们站在位置 `i` 时，我们不知道未来的 `nums[j]` 是什么。

- **错误做法**：把 `nums[i]` 存起来，等以后去匹配。（这会导致方向反了，且受前导零影响）。
- **正确做法（悬赏模式）**：既然题目要求 `reverse(nums[i]) == nums[j]`，那我们在位置 `i` 时，直接计算出 `reverse(nums[i])`，并把它当作 **“期望值”** 存进 HashMap。
    - _潜台词_：“我翻转后是这个值，后面谁**原封不动**等于这个值，谁就是我的配对！”

#### 3. 贪心策略：如何保证“最小距离”？

- 题目要求返回**最小**绝对距离。
- 因为我们是**从左往右**遍历，下标 `i` 是越来越大的。
- 对于同一个“期望值”，如果它在前面出现过多次，**越靠右（下标越大）的出现位置，与未来匹配者的距离就越短**。
- **结论**：在 HashMap 中，如果 Key 已存在，直接用当前的 `i` **覆盖**旧的下标即可。这样永远保留了最近的一次出现位置。
**解答**

```java
class Solution {

    public int minMirrorPairDistance(int[] nums) {

        int ans = Integer.MAX_VALUE;

        // Key: 某个数字反转后的值, Value: 该数字在原数组中的下标

        // 含义：如果后面遇到了等于 Key 的数字，说明找到了镜像对

        Map<Integer, Integer> map = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {

            // 1. 先检查：当前数字 nums[i] 是否能和前面的数字组成镜像对

            // 即：前面是否存在某个 nums[k]，使得 reverse(nums[k]) == nums[i]

            if (map.containsKey(nums[i])) {

                ans = Math.min(ans, i - map.get(nums[i]));

            }

            // 2. 再记录：把当前数字反转后的值存入 map，供后面的数字匹配

            // 注意：为了保证距离最小，如果 map 中已经有了这个 key，我们应该保留下标更大的（更靠右的）

            // 但因为我们是求最小距离，且 i 是递增的，后面的 i 肯定比前面的大。

            // 等等！如果我们保留更大的 i，那么对于未来的 j，距离 j - i 会更小！

            // 所以，如果 key 已存在，我们应该【更新】为更大的 i。

            // 直接 put 即可覆盖旧值。

            int rev = reverse(nums[i]);

            map.put(rev, i);

        }

        return ans == Integer.MAX_VALUE ? -1 : ans;

    }



    public int reverse(int x) {

        int rev = 0;

        while (x != 0) {

            int pop = x % 10;

            x /= 10;          

            rev = rev * 10 + pop;

        }

        return rev;

    }

}
```

**思路**

**解答**

```java
class Solution {

    public long maximumProduct(int[] nums, int m) {

        // 1. 使用 long 类型防止溢出

        long ans = Long.MIN_VALUE;

        // 维护目前为止可以作为“开头”的元素的最大值和最小值

        // 初始时，还没有元素可以作为开头（因为至少要留 m-1 个位置给后面）

        long maxVal = Long.MIN_VALUE;

        long minVal = Long.MAX_VALUE;

        // 2. 从第 m-1 个元素开始遍历（下标从0开始，所以是 m-1）

        // 因为子序列长度至少为 m，所以结尾元素最早只能出现在下标 m-1 处

        for (int i = m - 1; i < nums.length; i++) {

            // 当前元素 nums[i] 作为结尾

            // 此时，下标为 i - m + 1 的元素刚刚变得“合法”，可以作为开头了

            // 我们将它纳入考虑范围，更新 maxVal 和 minVal

            // 情况A: 当前数是正数，乘以前面最大的数

            // 情况B: 当前数是负数，乘以前面最小的数

            long currentMax = Math.max((long)nums[i] * maxVal, (long)nums[i] * minVal);

            // 更新全局最大值

            ans = Math.max(ans, currentMax);

        }

        return ans;

    }

}
```

#### 题目 24

![题目截图](./figure/Pasted%20image%2020260901133919.png)

**思路**

这是一份为你整理的简短解题思路，适合写在代码注释或笔记里：

### 💡 核心思路：余数互补（同余法）

**1. 数学转换**  
题目要求 `(a + b) % 60 == 0`。  
根据取模性质，这等价于 **`(a % 60 + b % 60) % 60 == 0`**。  
也就是说，我们只关心每个数字除以 60 的**余数**。

**2. 寻找配对**  
对于当前数字 `t`，设其余数为 `r = t % 60`。为了凑成 60 的倍数，我们需要找一个之前的数字，其余数 `complement` 满足：

- 若 `r == 0`，则需要找余数为 `0` 的数。
- 若 `r != 0`，则需要找余数为 `60 - r` 的数。
- **统一公式**：需要找的余数为 `(60 - r) % 60`。

**3. 算法流程 (哈希表)**

- 遍历数组，计算当前数的余数 `r`。
- 计算目标余数 `target = (60 - r) % 60`。
- 查表：如果 Map 中已有 `target`，说明之前有数字能和当前数字配对，累加其出现次数到答案 `ans`。
- 存表：将当前余数 `r` 的次数 +1 存入 Map，供后续数字匹配。

**解答**

```java
class Solution {

    public int numPairsDivisibleBy60(int[] time) {

        int ans = 0;

        // Key: 余数 (0-59), Value: 该余数出现的次数

        Map<Integer, Integer> map = new HashMap<>();



        for (int t : time) {

            // 1. 计算当前数字的余数

            int remainder = t % 60;

            // 2. 计算需要的补数余数

            // 如果 remainder 是 0，补数是 0；如果 remainder 是 20，补数是 40

            int targetRemainder = (60 - remainder) % 60;



            // 3. 在 Map 中查找之前有多少个数字拥有这个补数余数

            if (map.containsKey(targetRemainder)) {

                ans += map.get(targetRemainder);

            }



            // 4. 将当前数字的余数存入 Map，供后面的数字匹配

            map.put(remainder, map.getOrDefault(remainder, 0) + 1);

        }

        return ans;

    }

}

```

#### 题目 28

![题目截图](./figure/Pasted%20image%2020260901230019.png)

**思路**

我们把公式 (nums[i]−nums[j])×nums[k](nums[i]−nums[j])×nums[k] 拆开看：

1. 当我们**固定中间的 jj** 时， nums[j]nums[j] 就是一个定值。
2. 为了让整个乘积最大，我们需要让前面的 (nums[i]−nums[j])(nums[i]−nums[j]) 尽可能大，同时让后面的 nums[k]nums[k] 也尽可能大（假设它们乘起来是正数的话）。
    - 要让 (nums[i]−nums[j])(nums[i]−nums[j]) 最大，因为 jj 固定了，我们就需要找一个在 jj 左边（ i<ji<j ）的 **最大的 nums[i]nums[i]** 。
    - 要让 nums[k]nums[k] 最大，我们就需要找一个在 jj 右边（ k>jk>j ）的 **最大的 nums[k]nums[k]** 。

所以，对于每一个固定的 jj ，它能贡献的最大值就是：  
`(j左边的最大值 - nums[j]) * (j右边的最大值)`

**解答**

```java
class Solution {

    public long maximumTripletValue(int[] nums) {

        int n = nums.length;

        // ==========================================

        // 核心思想：降维打击（固定中间变量 j）

        // ==========================================

        // 题目要求最大化: (nums[i] - nums[j]) * nums[k]，其中 i < j < k

        // 如果我们枚举中间的 j，那么公式就变成了: (nums[i]的最大值 - nums[j]) * nums[k]的最大值

        // 为了让结果最大，对于固定的 j，我们需要：

        // 1. j 左边 (i < j) 的 nums[i] 尽可能大 -> 前缀最大值 (preMax)

        // 2. j 右边 (k > j) 的 nums[k] 尽可能大 -> 后缀最大值 (sufMax)

        // ==========================================

        // 第一步：预处理后缀最大值数组 (找右边的最大值)

        // ==========================================

        // sufMax[i] 表示从下标 i 到数组末尾 n-1 这个范围内的最大值

        // 多开一个空间 (n+1)，sufMax[n] 默认为 0，起到兜底作用

        int[] sufMax = new int[n + 1];

        // 从右往左遍历计算后缀最大值

        // 因为 k > j 且 j 至少为 1，所以 k 至少为 2。因此 i > 1 就足够覆盖所有需要的后缀了

        for (int i = n - 1; i > 1; i--) {

            sufMax[i] = Math.max(sufMax[i + 1], nums[i]);

        }

        // ==========================================

        // 第二步：一次遍历求解 (固定 j，动态维护左边最大值)

        // ==========================================

        // 初始化答案为 0。题目要求：如果所有满足条件的三元组的值都是负数，则返回 0。

        // 初始化为 0 可以让 Math.max 自动过滤掉所有负数结果。

        long ans = 0;

        // preMax 维护 j 左边的最大值。初始时 j=1，左边只有 nums[0]

        int preMax = nums[0];

        // 枚举中间的 j。

        // j 的范围是 [1, n-2] (即 j < n - 1)。

        // 原因：i < j 所以 j 最小是 1；j < k 所以 j 最大是 n-2 (给 k 留出最后一个位置 n-1)

        for (int j = 1; j < n - 1; j++) {

            // 核心公式计算：(左边最大 - 当前nums[j]) * 右边最大

            // 注意：必须强制转换为 long，防止两个 int 相乘溢出 32 位整数范围！

            // sufMax[j+1] 是因为 k 必须严格大于 j，所以取 j+1 开始的后缀最大值

            long currentVal = (long) (preMax - nums[j]) * sufMax[j + 1];

            // 更新全局最大值

            ans = Math.max(ans, currentVal);

            // 更新左边最大值，为下一个 j (即 j+1) 做准备

            // 放在计算之后，是因为对于当前的 j，nums[j] 属于"中间"，不能算作"左边"的 i

            preMax = Math.max(preMax, nums[j]);

        }

        return ans;

    }

}
```

#### 题目 29

![题目截图](./figure/Pasted%20image%2020260901231338.png)

**思路**
这道题是一道余数互补的问题，不过这里有一个坑就是，负数取余还是负数，所以可以int rem = (arr[i] % k + k) % k;确保是[0 - k-1]内，然后把自己的余数存入map中，等待后续来配对

**解答**

```java
class Solution {

    public boolean canArrange(int[] arr, int k) {

        int n = arr.length;

        int ans = 0;

        // key: 余数, value: 该余数目前还没配对的数量

        Map<Integer, Integer> map = new HashMap<>();



        for (int i = 0; i < n; i++) {

            // 1. 处理负数取模，保证余数在 [0, k-1] 之间

            int rem = (arr[i] % k + k) % k;

            // 2. 计算需要的互补余数。注意这里也要 % k，处理 rem=0 的情况

            int target = (k - rem) % k;



            // 3. 检查 map 里有没有需要的互补余数

            if (map.containsKey(target) && map.get(target) > 0) {

                // 配对成功！

                ans++;

                // 把 map 里那个互补余数的数量减 1

                map.put(target, map.get(target) - 1);

            } else {

                // 配对失败，把自己的余数存进去，等待后面的数字来配对

                map.put(rem, map.getOrDefault(rem, 0) + 1);

            }

        }

        // 4. 判断是否刚好配成了 n/2 对

        return ans == n / 2;

    }

}
```

#### 题目 30

![题目截图](./figure/Pasted%20image%2020260901232533.png)

**思路**
用前缀和把整个数组的类和表示出来，核心在f方法中，它在遍历每个分界点，在他便利的同时，使用maxSumA变量来维护左边长度为firstLen的子数组元素和最大的，并且用res保存答案，最后在主代码里面比较一下 firstLen和secondLen谁在左谁在右更大的情况就好了

**解答**

```java
class Solution {

    public int maxSumTwoNoOverlap(int[] nums, int firstLen, int secondLen) {

        int n = nums.length;



        // 前缀和：s[i] = nums[0] + nums[1] + ... + nums[i-1]

        // 任意子数组 nums[l..r] 的和 = s[r+1] - s[l]，O(1) 查询

        int[] s = new int[n + 1];

        for (int i = 0; i < n; i++) {

            s[i + 1] = s[i] + nums[i];

        }



        // 分两种情况取最大值：

        //   1. firstLen 的子数组在左，secondLen 的子数组在右

        //   2. secondLen 的子数组在左，firstLen 的子数组在右

        return Math.max(f(s, firstLen, secondLen), f(s, secondLen, firstLen));

    }



    // f(s, firstLen, secondLen)：

    // 求「长度为 firstLen 的子数组 A 在左边，长度为 secondLen 的子数组 B 在右边」的最大和

    private int f(int[] s, int firstLen, int secondLen) {

        int maxSumA = 0; // 维护：在当前 B 的左边，所有合法 A 子数组中的最大和

        int res = 0;     // 全局答案



        // i 是前缀和数组的下标，对应 B 的右端点的后一位

        // i 从 firstLen+secondLen 开始：保证左边至少放得下 A，且 B 至少有 secondLen 个元素

        // i 最大到 s.length-1 = n：此时 B 占据 nums[n-secondLen .. n-1]

        for (int i = firstLen + secondLen; i < s.length; ++i) {



            // 【更新 maxSumA】

            // 当 B 的右端点固定在 i-1 时，B 占据 nums[i-secondLen .. i-1]

            // 紧贴 B 左边的 A 候选 = nums[i-secondLen-firstLen .. i-secondLen-1]

            //   其和 = s[i-secondLen] - s[i-secondLen-firstLen]

            // 随着 i 增大，不断有新的 A 候选出现，maxSumA 记录所有候选中的最大值

            // 注意：最优的 A 不一定紧贴 B，可以在更左边，maxSumA 已经涵盖了这种情况

            maxSumA = Math.max(maxSumA, s[i - secondLen] - s[i - secondLen - firstLen]);



            // 【更新 res】

            // 当前 B 的和 = s[i] - s[i-secondLen]，即 nums[i-secondLen .. i-1]

            // 用「左边最优 A」+「当前 B」更新全局答案

            res = Math.max(res, maxSumA + s[i] - s[i - secondLen]);

        }



        return res;

    }

}

```

![题目截图](./figure/Pasted%20image%2020260901234717.png)

**思路**
数组元素值，代表这个奖品在哪个位置，同一个元素个数代表代表有几个奖品

**解答**

```java
class Solution {

    public int maximizeWin(int[] prizePositions, int k) {

        int n = prizePositions.length;

        // 【特判优化】

        // 如果两根线段的总覆盖范围 (2 * k) 加上中间可能的间隙，

        // 已经大于等于整个奖品分布的跨度，说明两根线段足以覆盖所有奖品。

        // 注意：这里用 k*2+1 是因为线段长度是 k，覆盖的坐标差是 k。

        // 两根线段最多能覆盖的坐标跨度大约是 2*k。如果总跨度 <= 2*k，肯定能全覆盖。

        // (题目中更严谨的判断其实是看两根线段能不能包住首尾，这里保留原代码的特判逻辑)

        if (k * 2 + 1 >= prizePositions[n - 1] - prizePositions[0]) {

            return n;

        }



        int ans = 0;

        int left = 0;

        // 【核心数据结构：mx 数组】

        // mx[i] 的含义：在数组的前 i 个元素中（即下标 0 到 i-1），

        // 单独选一根合法线段，最多能覆盖多少个奖品。

        // 它是一个“前缀最大值”数组，天然单调不减。

        int[] mx = new int[n + 1];



        // 【滑动窗口：枚举右边线段的右端点】

        for (int right = 0; right < n; right++) {

            // 1. 调整左边界 left，保证当前窗口 [left, right] 是一根合法的线段

            // 合法条件：线段覆盖的坐标差 <= k

            // 即：prizePositions[right] - prizePositions[left] <= k

            while (prizePositions[right] - prizePositions[left] > k) {

                left++;

            }



            // 2. 计算当前状态下的最大奖品数

            // 此时，我们将问题分成了两部分：

            //    - 右边线段：就是当前的窗口 [left, right]，覆盖奖品数为 (right - left + 1)

            //    - 左边线段：必须在当前窗口的左边，即下标范围 [0, left-1]

            //

            // 【为什么是 mx[left]？】

            // 因为 mx[left] 存的正是“前 left 个元素（下标 0 到 left-1）”中的历史最大单线段覆盖数。

            // 随着 left 不断右移，被甩在左边的元素的最优解早就被记录在 mx 里了。

            // 所以：左边历史最优 (mx[left]) + 右边当前最优 (right - left + 1) = 两根线段的总和

            ans = Math.max(ans, mx[left] + right - left + 1);



            // 3. 维护 mx 数组（更新前缀最大值）

            // mx[right+1] 代表前 right+1 个元素（下标 0 到 right）的最大值。

            // 它等于：max(之前的最大值 mx[right], 当前窗口的长度 right-left+1)

            mx[right + 1] = Math.max(mx[right], right - left + 1);

        }



        return ans;

    }

}
```

#### 题目 33

![题目截图](./figure/Pasted%20image%2020260902092418.png)

**思路**

如果 colors[0]=colors[n−1]，那么答案是 n−1。则设 c=colors[0]=colors[n−1]。
设最大距离来自房子 i 和房子 j。由于题目要求 colors[i]=colors[j]，所以这两个颜色不可能都等于 c。如果 colors[i]=c，那么 j 必然是离 i 最远的 0 或者 n−1（这两栋房子的颜色与房子 i 不同）。这意味着，0 或者 n−1 必然参与最大距离的计算。对于房子 0 来说，另一栋房子越远（越靠右）越好。从右往左找到颜色不等于 c 的房子 colors[r]，距离为 r−0=r。对于房子 n−1 来说，另一栋房子越远（越靠左）越好。从左往右找到颜色不等于 c 的房子colors[ℓ]，距离为 n−1−ℓ。答案为二者的最大值max(r,n−1−ℓ)

**解答**

```java
class Solution {

    public int maxDistance(int[] colors) {

        int n = colors.length;

        int c = colors[0];

        if(c != colors[n-1]){

            return n-1;

        }



        int r = n-2;

        while(colors[r]==c){

            r--;

        }



        int l = 1;

        while(colors[l]==c){

            l++;

        }

    return Math.max(r,n-1-l);

    }

}
```

```java
class Solution {
```

```java
        Arrays.fill(colSum,-1);

                colSum[j]+=row[j];
```
