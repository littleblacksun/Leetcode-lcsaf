## 核心思想：模拟与贪心

这道题的本质是**模拟**栈的操作过程，配合**贪心**策略跳过不需要的数字。

因为给定的数字流是严格递增的 `1, 2, 3, ..., n`，而目标数组 `target` 也是严格递增的。因此，我们可以按顺序遍历数字流，遇到 `target` 里需要的数字就保留（Push），遇到不需要的数字就丢弃（Push 后立刻 Pop）。

## 关键优化：确定遍历的终点

题目给定了范围 `[1, n]`，但我们**不需要遍历到 `n`**。
由于 `target` 是递增的，只要栈里构建出了 `target` 的最后一个元素，整个目标就完成了。后面的数字根本不需要处理。
因此，我们只需要遍历到 `target` 的最大值，即 `target[target.length - 1]`。

- `int mx = target[target.length - 1];` （这就是代码中 `mx` 变量的意义，用于提前终止循环，节省时间）。

**解答**

```java
class Solution {
    public List<String> buildArray(int[] target, int n) {
        List<String> ans = new ArrayList<>();
        int mx = target[target.length-1];
        int i = 0;
        for(int x = 1;x<=mx;x++){
            ans.add("Push");
            if(x == target[i]){
                i++;
            }else{
                ans.add("Pop");
            }
        }
        return ans;
    }
}
```

```java
import java.util.ArrayList;
import java.util.List;
class Solution {
    public int calPoints(String[] operations) {
        // 使用 List 来模拟栈，存储每一轮有效的得分
        // 之所以用 List 而不是 Stack，是因为后续需要频繁获取倒数第二个元素（st.get(st.size()-2)）
        // List 的随机访问特性让这种操作非常方便
        List<Integer> st = new ArrayList<>();
        // 遍历所有的操作指令
        for (String op : operations) {
            // 使用 switch 对字符串的第一个字符进行判断，比 equals 更简洁高效
            switch (op.charAt(0)) {
            case '+':
                // 如果是 "+"，新得分 = 前两次得分之和
                // st.size()-2 是倒数第二个元素（前两次得分）
                // st.size()-1 是倒数第一个元素（前一次得分）
                st.add(st.get(st.size() - 2) + st.get(st.size() - 1));
                break;
            case 'D':
                // 如果是 "D"，新得分 = 前一次得分的两倍
                // st.get(st.size() - 1) 获取当前的栈顶元素（前一次得分）
                st.add(st.get(st.size() - 1) * 2);
                break;
            case 'C':
                // 如果是 "C"，说明前一次得分无效，需要移除
                // 移除 List 的最后一个元素，相当于栈的 pop 操作
                st.remove(st.size() - 1);
                break;
            default:
                // 如果不是特殊字符，说明是数字字符串（比如 "5", "-2"）
                // 将其转换成整数并添加到 List 末尾，相当于栈的 push 操作
                st.add(Integer.parseInt(op));
            }
        }
        // 遍历 List，累加所有剩余的得分，计算总和
        int sum = 0;
        for (int x : st) {
            sum += x;
        }
        // 返回最终的总分
        return sum;
    }
}
```

```java
class Solution {
    public String removeStars(String s) {
        List<Character> ans = new ArrayList<>();
        char[] c = s.toCharArray();
        for(char ca : c){
            if(ca=='*'){
                ans.remove(ans.size()-1);
            }else{
                ans.add(ca);
            }
        }
        // 2. 将 List<Character> 拼接成 String 返回
        // 使用 StringBuilder 效率最高
        StringBuilder sb = new StringBuilder();
        for (char ch : ans) {
            sb.append(ch); // 遍历列表，把字符追加到 StringBuilder 中
        }
        return sb.toString(); // 转换为 String 返回
    }
}

import java.util.Deque;
import java.util.ArrayDeque;

class Solution {
    public String removeStars(String s) {
        // 1. 创建一个栈 (使用 Deque 接口，ArrayDeque 实现)
        Deque<Character> stack = new ArrayDeque<>();
        // 2. 遍历字符串
        for (char c : s.toCharArray()) {
            if (c == '*') {
                // 遇到星号，弹出栈顶元素（相当于移除左侧最近的字符）
                // 题目保证栈不为空，所以直接 pop 是安全的
                stack.pop();
            } else {
                // 遇到普通字符，压入栈中
                stack.push(c);
            }
        }

        // 3. 将栈中的字符拼接成字符串返回
        StringBuilder sb = new StringBuilder();
        // 注意：直接遍历 Deque 是从栈底到栈顶的顺序（即正序）
        // 所以我们直接遍历拼接即可
        for (char c : stack) {
            sb.append(c);
        }
        return sb.toString();
    }
}
```

**思路**
**`history.subList(cur, history.size())`**
`subList(fromIndex, toIndex)` 返回的是原列表的一个**视图（view）**，不是拷贝。它表示 `[cur, history.size())` 这个左闭右开区间内的元素。
 **`.clear()`**
`clear()` 会删除这个视图中的所有元素。关键点在于：**因为 subList 是视图，对它的修改会直接反映到原列表上**。所以删除 `[C, D, E]` 等于直接从 `history` 里删掉这些元素。

**解答**

```java
class BrowserHistory {
    private final List<String> history = new ArrayList<>();
    private int cur = 0;
    public BrowserHistory(String homepage) {
        history.add(homepage);
    }

    public void visit(String url) {
        cur ++ ;
        history.subList(cur,history.size()).clear();
        history.add(url);
    }

    public String back(int steps) {
        cur = Math.max(cur-steps,0);
        return history.get(cur);
    }

    public String forward(int steps) {
        cur = Math.min(cur+steps,history.size()-1);
        return history.get(cur);
    }
}
```

**思路**
 核心思路：模拟栈的入栈和出栈

1. **用一个栈模拟入栈过程**，按顺序遍历 `pushed` 数组，每个元素都先入栈。

2. **每入栈一个元素后，立刻检查**：栈顶元素是否等于 `popped` 当前需要出栈的元素？

    - 如果相等，就**弹出栈顶**，并把 `popped` 的指针后移一位。

    - 用 `while` 循环反复检查，因为可能连续弹出多个。

3. **遍历结束后，判断栈是否为空**：

    - 栈空 → 说明所有元素都按 `popped` 的顺序成功弹出，返回 `true`。

    - 栈不空 → 说明有元素卡在栈里出不来，顺序不合法，返回 `false`。

**解答**

```java
import java.util.ArrayDeque;
import java.util.Deque;
class Solution {
    public boolean validateStackSequences(int[] pushed, int[] popped) {
        // 使用 Deque 接口模拟栈，底层是数组，性能好
        Deque<Integer> stack = new ArrayDeque<>();
        int j = 0; // 指向 popped 数组中当前待匹配的元素
        // 遍历 pushed 数组，模拟入栈过程
        for (int x : pushed) {
            // 1. 入栈
            stack.push(x);
            // 2. 循环检查：栈不为空，且栈顶元素等于 popped 当前需要的元素
            // peek() 查看栈顶但不弹出，pop() 弹出栈顶
            while (!stack.isEmpty() && stack.peek() == popped[j]) {
                stack.pop(); // 出栈
                j++;         // 指向 popped 的下一个待匹配元素
            }
        }
        // 3. 如果 pushed 遍历完，且栈为空，说明 popped 是合法的出栈序列
        return stack.isEmpty();
    }
}
```

**思路**
**核心思路：分割 + 栈模拟**

1. **分割字符串**：用 `/` 把路径切开，得到字符串数组。（注意会产生空字符串 `""`）

2. **遍历处理每一部分**：

    - 遇到 `""`（空串）或 `"."`：**跳过**，什么都不做。

    - 遇到 `".."`：**出栈**（前提是栈不为空，防止越界）。

    - 遇到其他有效目录名：**入栈**。

3. **拼接结果**：遍历栈（从栈底到栈顶），每个元素前面加一个 `/` 拼起来。

4. **处理边界**：如果最后栈为空，直接返回 `"/"`。

**解答**

```java
class Solution {
    public String simplifyPath(String path) {
        String[] paths = path.split("/");
        List<String> stack = new ArrayList<>(); // 改名成 stack 更直观
        for (String p : paths) {
            // 1. 遇到空串或 "."，跳过
            if (p.equals("") || p.equals(".")) {
                continue;
            }
            // 2. 遇到 ".."，出栈（前提是栈不为空）
            else if (p.equals("..")) {
                if (!stack.isEmpty()) {
                    stack.remove(stack.size() - 1);
                }
            }
            // 3. 其他情况，入栈
            else {
                stack.add(p);
            }
        }
        // 接下来就是拼接了……
        if(stack.isEmpty()){
            return "/";
        }
        StringBuilder sb = new StringBuilder();
        for(String dir : stack){
            sb.append("/");
            sb.append(dir);
        }
        return sb.toString();
    }
}
```

**思路**


**核心贪心：** 遇到 `*` 时，删除它**左边最靠右**的那个最小字符。

**为什么删最靠右的？** 靠左的字符在结果中权重更大，保留靠左的小字符能让最终字典序更小。

**做法：边遍历边处理**
1. 用 `t[26]` 个 `List`，`t[i]` 存字母 `'a'+i` 当前出现的所有下标。
2. 从左到右遍历字符串：
   - 遇到字母：把下标加入对应 `t[idx]`。
   - 遇到 `*`：从 `'a'` 到 `'z'` 找第一个非空的 `t[idx]`，弹出**队尾**（最靠右的最小字符），标记删除。
3. 最后跳过 `*` 和被删除的字符，拼接结果。

**为什么天然满足"只能删左边"？**
因为我们是边遍历边加入的，`t` 里只存了当前 `*` 左边的字母，右边的还没进来，不可能被误删。

**复杂度：** 每个字符最多入队出队一次，找最小最多扫 26 次，总体 O(26N) = O(N)。

**解答**

```java
class Solution {
    public String clearStars(String s) {
        char[] c = s.toCharArray();
        List<Integer>[] t = new ArrayList[26];
        for(int i = 0;i<26;i++){
            t[i] = new ArrayList<>();
        }
        boolean[] deleted = new boolean[c.length];
        for(int i = 0;i<c.length;i++){
            if(c[i]!='*'){
                int idx =c[i]-'a';
                t[idx].add(i);
            }else{
                for(int idx = 0;idx<26;idx++){
                    if(!t[idx].isEmpty()){
                        int p = t[idx].remove(t[idx].size()-1);
                        deleted[p] = true;
                        break;
                    }
                }
            }
        }
        StringBuilder sb = new StringBuilder();
        for(int i = 0;i<c.length;i++){
            if(c[i]=='*' || deleted[i]==true){
                continue;
            }else{
                sb.append(c[i]);
            }
        }
        return sb.toString();
    }
}
```
