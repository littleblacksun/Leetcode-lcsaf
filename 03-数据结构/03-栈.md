## 核心思想：模拟与贪心

这道题的本质是**模拟**栈的操作过程，配合**贪心**策略跳过不需要的数字。

因为给定的数字流是严格递增的 `1, 2, 3, ..., n`，而目标数组 `target` 也是严格递增的。因此，我们可以按顺序遍历数字流，遇到 `target` 里需要的数字就保留（Push），遇到不需要的数字就丢弃（Push 后立刻 Pop）。

## 关键优化：确定遍历的终点

题目给定了范围 `[1, n]`，但我们**不需要遍历到 `n`**。
由于 `target` 是递增的，只要栈里构建出了 `target` 的最后一个元素，整个目标就完成了。后面的数字根本不需要处理。
因此，我们只需要遍历到 `target` 的最大值，即 `target[target.length - 1]`。

- `int mx = target[target.length - 1];` （这就是代码中 `mx` 变量的意义，用于提前终止循环，节省时间）。

**解答**

```java
class Solution {
    public List<String> buildArray(int[] target, int n) {
        List<String> ans = new ArrayList<>();
        int mx = target[target.length-1];
        int i = 0;
        for(int x = 1;x<=mx;x++){
            ans.add("Push");
            if(x == target[i]){
                i++;
            }else{
                ans.add("Pop");
            }
        }
        return ans;
    }
}
```

```java
import java.util.ArrayList;
import java.util.List;
class Solution {
    public int calPoints(String[] operations) {
        // 使用 List 来模拟栈，存储每一轮有效的得分
        // 之所以用 List 而不是 Stack，是因为后续需要频繁获取倒数第二个元素（st.get(st.size()-2)）
        // List 的随机访问特性让这种操作非常方便
        List<Integer> st = new ArrayList<>();
        // 遍历所有的操作指令
        for (String op : operations) {
            // 使用 switch 对字符串的第一个字符进行判断，比 equals 更简洁高效
            switch (op.charAt(0)) {
            case '+':
                // 如果是 "+"，新得分 = 前两次得分之和
                // st.size()-2 是倒数第二个元素（前两次得分）
                // st.size()-1 是倒数第一个元素（前一次得分）
                st.add(st.get(st.size() - 2) + st.get(st.size() - 1));
                break;
            case 'D':
                // 如果是 "D"，新得分 = 前一次得分的两倍
                // st.get(st.size() - 1) 获取当前的栈顶元素（前一次得分）
                st.add(st.get(st.size() - 1) * 2);
                break;
            case 'C':
                // 如果是 "C"，说明前一次得分无效，需要移除
                // 移除 List 的最后一个元素，相当于栈的 pop 操作
                st.remove(st.size() - 1);
                break;
            default:
                // 如果不是特殊字符，说明是数字字符串（比如 "5", "-2"）
                // 将其转换成整数并添加到 List 末尾，相当于栈的 push 操作
                st.add(Integer.parseInt(op));
            }
        }
        // 遍历 List，累加所有剩余的得分，计算总和
        int sum = 0;
        for (int x : st) {
            sum += x;
        }
        // 返回最终的总分
        return sum;
    }
}
```

```java
import java.util.Deque;
import java.util.ArrayDeque;

class Solution {
    public String removeStars(String s) {
        // 1. 创建一个栈 (使用 Deque 接口，ArrayDeque 实现)
        Deque<Character> stack = new ArrayDeque<>();
        // 2. 遍历字符串
        for (char c : s.toCharArray()) {
            if (c == '*') {
                // 遇到星号，弹出栈顶元素（相当于移除左侧最近的字符）

                stack.push(c);
            }

        StringBuilder sb = new StringBuilder();
        // 注意：直接遍历 Deque 是从栈底到栈顶的顺序（即正序）
        // 所以我们直接遍历拼接即可
        for (char c : stack) {
            sb.append(c);
        }
```

**思路**
 核心思路：模拟栈的入栈和出栈

1. **用一个栈模拟入栈过程**，按顺序遍历 `pushed` 数组，每个元素都先入栈。

2. **每入栈一个元素后，立刻检查**：栈顶元素是否等于 `popped` 当前需要出栈的元素？

    - 如果相等，就**弹出栈顶**，并把 `popped` 的指针后移一位。

    - 用 `while` 循环反复检查，因为可能连续弹出多个。

3. **遍历结束后，判断栈是否为空**：

    - 栈空 → 说明所有元素都按 `popped` 的顺序成功弹出，返回 `true`。

    - 栈不空 → 说明有元素卡在栈里出不来，顺序不合法，返回 `false`。

**解答**

```java
import java.util.ArrayDeque;
import java.util.Deque;
class Solution {
    public boolean validateStackSequences(int[] pushed, int[] popped) {
        // 使用 Deque 接口模拟栈，底层是数组，性能好
        Deque<Integer> stack = new ArrayDeque<>();
        int j = 0; // 指向 popped 数组中当前待匹配的元素
        // 遍历 pushed 数组，模拟入栈过程
        for (int x : pushed) {
            // 1. 入栈
            stack.push(x);
            // 2. 循环检查：栈不为空，且栈顶元素等于 popped 当前需要的元素
            // peek() 查看栈顶但不弹出，pop() 弹出栈顶
            while (!stack.isEmpty() && stack.peek() == popped[j]) {
                stack.pop(); // 出栈
                j++;         // 指向 popped 的下一个待匹配元素
            }
        }
        // 3. 如果 pushed 遍历完，且栈为空，说明 popped 是合法的出栈序列
        return stack.isEmpty();
    }
}
```

**思路**
**核心思路：分割 + 栈模拟**

1. **分割字符串**：用 `/` 把路径切开，得到字符串数组。（注意会产生空字符串 `""`）

2. **遍历处理每一部分**：

    - 遇到 `""`（空串）或 `"."`：**跳过**，什么都不做。

    - 遇到 `".."`：**出栈**（前提是栈不为空，防止越界）。

    - 遇到其他有效目录名：**入栈**。

3. **拼接结果**：遍历栈（从栈底到栈顶），每个元素前面加一个 `/` 拼起来。

4. **处理边界**：如果最后栈为空，直接返回 `"/"`。

**解答**

```java
class Solution {
    public String simplifyPath(String path) {
        String[] paths = path.split("/");
        List<String> stack = new ArrayList<>(); // 改名成 stack 更直观
        for (String p : paths) {
            // 1. 遇到空串或 "."，跳过
            if (p.equals("") || p.equals(".")) {
                continue;
            }
            // 2. 遇到 ".."，出栈（前提是栈不为空）
            else if (p.equals("..")) {
                if (!stack.isEmpty()) {
                    stack.remove(stack.size() - 1);
                }
            }
            // 3. 其他情况，入栈
            else {
                stack.add(p);
            }
        }
        // 接下来就是拼接了……
        if(stack.isEmpty()){
            return "/";
        }
        StringBuilder sb = new StringBuilder();
        for(String dir : stack){
            sb.append("/");
            sb.append(dir);
        }
        return sb.toString();
    }
}
```

**思路**


**核心贪心：** 遇到 `*` 时，删除它**左边最靠右**的那个最小字符。

**为什么删最靠右的？** 靠左的字符在结果中权重更大，保留靠左的小字符能让最终字典序更小。

**做法：边遍历边处理**
1. 用 `t[26]` 个 `List`，`t[i]` 存字母 `'a'+i` 当前出现的所有下标。
2. 从左到右遍历字符串：
   - 遇到字母：把下标加入对应 `t[idx]`。
   - 遇到 `*`：从 `'a'` 到 `'z'` 找第一个非空的 `t[idx]`，弹出**队尾**（最靠右的最小字符），标记删除。
3. 最后跳过 `*` 和被删除的字符，拼接结果。

**为什么天然满足"只能删左边"？**
因为我们是边遍历边加入的，`t` 里只存了当前 `*` 左边的字母，右边的还没进来，不可能被误删。

**复杂度：** 每个字符最多入队出队一次，找最小最多扫 26 次，总体 O(26N) = O(N)。

**解答**

```java
class Solution {
    public String clearStars(String s) {
        char[] c = s.toCharArray();
        List<Integer>[] t = new ArrayList[26];
        for(int i = 0;i<26;i++){
            t[i] = new ArrayList<>();
        }
        boolean[] deleted = new boolean[c.length];
        for(int i = 0;i<c.length;i++){
            if(c[i]!='*'){
                int idx =c[i]-'a';
                t[idx].add(i);
            }else{
                for(int idx = 0;idx<26;idx++){
                    if(!t[idx].isEmpty()){
                        int p = t[idx].remove(t[idx].size()-1);
                        deleted[p] = true;
                        break;
                    }
                }
            }
        }
        StringBuilder sb = new StringBuilder();
        for(int i = 0;i<c.length;i++){
            if(c[i]=='*' || deleted[i]==true){
                continue;
            }else{
                sb.append(c[i]);
            }
        }
        return sb.toString();
    }
}
```

![题目截图](./figure/Pasted%20image%2020260915163829.png)

**思路**
**1. 核心考点**

- 设计一个能在 **O(1) 时间**内获取最小值的栈。
- 考察对**辅助栈（双栈）**思想的理解，以及 Java 集合类（`Deque` / `ArrayDeque`）的熟练使用。

**2. 核心思路：双栈协同**
- **`dataStack`（数据栈）**：负责正常的 `push`、`pop`、`top` 操作，保存所有元素。
- **`minStack`（最小栈）**：专门维护最小值，**栈顶永远是当前数据栈中的最小值**。

**3. 关键实现细节（易错点）**
- **同步压栈**：`push` 时，若新值 `<= minStack` 栈顶（注意是 `<=` 而非 `<`），则同步压入 `minStack`。这样能正确处理**重复最小值**，防止 `minStack` 提前被弹空。
- **同步出栈**：`pop` 时，若 `dataStack` 栈顶与 `minStack` 栈顶相等，则 `minStack` 也弹出。
- **Integer 比较陷阱**：判断两个栈顶是否相等时，**必须用 `.equals()`**，绝对不能用 `==`（`==` 比较的是对象地址，超出 -128~127 范围会出错）。

**4. 复杂度分析**
- **时间复杂度**：`push`、`pop`、`top`、`getMin` 均为 **O(1)**。
- **空间复杂度**：**O(n)**。最坏情况（如递减序列）下，`minStack` 需要存储所有元素。
**解答**
```java
class MinStack {
    private final Deque<Integer> dataStack;
    private final Deque<Integer> minStack;
    public MinStack() {
        dataStack = new ArrayDeque<>();
        minStack = new ArrayDeque<>();
    }
    public void push(int value) {
        dataStack.push(value);
        if (minStack.isEmpty() || value <= minStack.peek()) {
            minStack.push(value);
        }
    }
    public void pop() {
         // 先比较，再弹 dataStack
        if (dataStack.peek().equals(minStack.peek())) {
            minStack.pop();
        }
        dataStack.pop();
    }
    public int top() {
        return dataStack.peek();
    }
    public int getMin() {
        return minStack.peek();
    }
}
```

```java
class CustomStack {
    private int[] stack;
    private int top; // 指向栈顶元素的下一个位置，也代表了当前栈中元素的个数

    public CustomStack(int maxSize) {
        stack = new int[maxSize];
        top = 0;
    }

    public void push(int x) {
        if (top < stack.length) {
            stack[top] = x;
            top++;
        }
    }

    public int pop() {
        if (top == 0) {
            return -1;
        }
        top--;
        return stack[top];
    }

    public void increment(int k, int val) {
        // 需要增加的元素个数是 k 和 当前栈大小 top 的较小值
        int limit = Math.min(k, top);
        for (int i = 0; i < limit; i++) {
            stack[i] += val;
        }
    }
}
```

**思路**
这道题（LeetCode 636. 函数的独占时间）是一道非常经典的**栈模拟题**。它的核心难点不在于算法本身，而在于**对时间区间的精确计算**。

下面为你做一个简短的总结，帮你彻底吃透这道题：

 **🎯 核心思想：栈 + 时间锚点**

1. **栈（Stack）**：用来模拟单线程 CPU 的函数调用过程。遇到 `start` 就压栈，遇到 `end` 就弹栈。栈顶始终是当前正在执行的函数。

2. **时间锚点（`prevTime`）**：记录上一个日志处理完后，下一个函数可以从哪个时间点开始执行。每次遇到新日志，就用当前时间戳和 `prevTime` 计算时间差，累加到对应函数的独占时间上。


 **⚠️ 两个必须记住的“坑”**

1. **字符串比较**：Java 中比较字符串内容必须用 `.equals()`，不能用 `==`。

2. **空指针异常**：`Deque` 的 `peek()` 在栈为空时返回 `null`，赋值给 `int` 会自动拆箱导致 `NullPointerException`。**在 `peek()` 之前必须加 `!stack.isEmpty()` 判断。**


 **🧮 时间计算的核心口诀（最容易出错的地方）**

|动作|当前函数是否包含该时间点|计算时间差|更新 `prevTime`|
|---|---|---|---|
|**start**|**不包含**（属于新函数）|`timeStep - prevTime`|`prevTime = timeStep`|
|**end**|**包含**（属于当前函数）|`timeStep - prevTime + 1`|`prevTime = timeStep + 1`|

> **理解技巧**：
>
> - `start` 的时间点是新函数的起点，所以旧函数算到它前面一秒为止，不 +1。
>
> - `end` 的时间点是当前函数的终点，算独占时间时要包含这一秒，所以 +1。
>
> - 更新 `prevTime` 时，如果是 `end`，因为结束点已被占用，下一个函数必须从下一秒开始，所以也要 +1。

**解答**
```java
class Solution {
    public int[] exclusiveTime(int n, List<String> logs) {
        Deque<Integer> stack = new ArrayDeque<>();
        int[] ans = new int[n];
        int prevTime = 0;
        for(var log:logs){
            String[] L = log.split(":");
            int id = Integer.parseInt(L[0]);
            int timeStep = Integer.parseInt(L[2]);
            if(L[1].equals("start")){
                  if (!stack.isEmpty()) {
                    int lastId = stack.peek();
                    ans[lastId] += timeStep - prevTime;
                }
                prevTime = timeStep;
                stack.push(id);
            }
            if(L[1].equals("end")){
                ans[id]+=timeStep-prevTime+1;
                prevTime = timeStep+1;
                stack.pop();
            }
        }
        return ans;
    }
}
```

![题目截图](./figure/Pasted%20image%2020260918224122.png)

**思路**
2434. 机器人打印字典序最小字符串 —— 核心思路
一句话总结
**预知未来（后缀最小值），决定当下（栈顶出不出）。**
 贪心规则
| 比较 | 操作 |
|:---|:---|
| 栈顶 ≤ `s` 剩余最小值 | **出栈**（写纸上） |
| 栈顶 > `s` 剩余最小值 | **入栈**（继续从 `s` 拿） |
关键工具
`minS[i]` = `s[i...n-1]` 的最小字符（后缀最小值）
- 哨兵：`minS[n] = '{'`，防越界
算法框架
```
while (i < n || 栈非空) {
    if (栈非空 && 栈顶 <= minS[i]) 出栈;
    else 入栈 s[i++];
}
```
易错点
1. 比的是**栈顶**，不是 `s[i]`
2. 判断放在**每轮开头**
3. 用 `<=`，哨兵不能省
复杂度
时间 `O(n)`，空间 `O(n)`
**解答**
```java
class Solution {
    public String robotWithString(String s) {
        int n = s.length();
        char[] c = s.toCharArray();
        // 1. 预处理后缀最小值数组
        // minS[i] 表示 s[i...n-1] 中最小的字符
        char[] minS = new char[n + 1];
        minS[n] = '{'; // 哨兵字符，比 'z' 大，保证 i == n 时比较安全
        for (int i = n - 1; i >= 0; i--) {
            minS[i] = (char) Math.min(c[i], minS[i + 1]);
        }
        // 2. 用 StringBuilder 模拟栈 t 和结果 ans
        StringBuilder stack = new StringBuilder(); // 机器人手中的 t
        StringBuilder ans = new StringBuilder();   // 写到纸上的结果
        int i = 0; // 指向 s 的指针
        // 3. 模拟操作
        while (i < n || stack.length() > 0) {
            // 如果栈不为空，且栈顶字符 <= s 中剩余字符的最小值
            // 说明栈顶已经是最小的了，可以出栈写到纸上
            if (stack.length() > 0 && stack.charAt(stack.length() - 1) <= minS[i]) {
                ans.append(stack.charAt(stack.length() - 1));
                stack.deleteCharAt(stack.length() - 1);
            } else {
                // 否则，把 s 的当前字符入栈
                stack.append(c[i]);
                i++;
            }
        }
        return ans.toString();
    }
}
```

```java
        List<Character> t = new ArrayList<>();
        for(int i = 0 ; i<c.length;i++){
            if(c[i]=='B' &&  !t.isEmpty() && t.get(t.size()-1) == 'A'){
                t.remove(t.size()-1);
                continue;
            }
            if(c[i]=='D' &&  !t.isEmpty()  && t.get(t.size()-1) == 'C'){
                t.remove(t.size()-1);
                continue;
            }
            t.add(c[i]);
        }
        return t.size();
    }
}
```

#### 题目 7

![题目截图](./figure/Pasted%20image%2020260918231822.png)

**思路**
`if(c[i] == stack.peek() && !stack.isEmpty())`  
这里如果栈是空的，`stack.peek()` 会返回 `null`，此时 `c[i] == null` 虽然不会报错（因为 `c[i]` 是 char，会触发自动装箱比较，结果是 false），但更好的习惯是**先判断空，再取栈顶**，避免逻辑混乱。  
应该改为：`if(!stack.isEmpty() && c[i] == stack.peek())`
**解答**
```java
class Solution {
    public String removeDuplicates(String s) {
        char[] c  = s.toCharArray();
        int n = c.length;
        Deque<Character> stack  = new ArrayDeque<>();
        for(int i = 0;i<n;i++){
            if(!stack.isEmpty() &&  c[i] == stack.peek()){
                stack.pop();
                continue;
            }
            stack.push(c[i]);
        }
        StringBuilder sb = new StringBuilder();
        for (char ch : stack) {
            sb.append(ch);
        }
        return sb.reverse().toString();
    }
}
```

```java
class Solution {
    public String makeGood(String s) {
        char[] c = s.toCharArray();
        Deque<Character> stack  = new ArrayDeque<>();
        for(char i : c){
            if(!stack.isEmpty() && ((char)(i + 32) == stack.peek() || (char)(i - 32) ==stack.peek())){
                stack.pop();
                continue;
            }
            stack.push(i);
        }
        StringBuilder sb = new StringBuilder();
        for(char k : stack){
            sb.append(k);
        }
        return sb.reverse().toString();
    }
}
```
