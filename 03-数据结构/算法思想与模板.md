## 前缀和：算法思想与解题模板

> **一句话理解**：前缀和不是单纯“提前算和”，而是把一个区间的信息转化为两个前缀状态之间的关系，从而避免反复遍历区间。

---

## 1. 基础定义

对于长度为 `n` 的数组 `nums`，定义长度为 `n + 1` 的前缀和数组：

```text
pre[0] = 0
pre[i + 1] = nums[0] + nums[1] + ... + nums[i]
```

因此，下标闭区间 `[left, right]` 的元素和为：

```text
sum(left, right) = pre[right + 1] - pre[left]
```

使用 `n + 1` 长度有两个好处：

1. `pre[0] = 0` 自然表示“前 0 个元素的和”。
2. 当 `left = 0` 时仍可直接套用统一公式，不必访问 `pre[-1]`，也不需要额外判断边界。

### 下标含义一定要统一

```text
pre[i] = nums[0 ... i - 1] 的和
```

也就是说，`pre[i]` 对应原数组前 `i` 个元素，而不是对应 `nums[i]`。

---

## 2. 前缀思想的本质

前缀结构保存的是“从起点走到当前位置时的累计状态”。一个子数组 `[left, right]`，就是右端状态去掉左端之前的状态。

| 原问题 | 前缀状态 | 区间 `[left, right]` 的信息 |
| --- | --- | --- |
| 区间和 | `pre[i + 1] = pre[i] + nums[i]` | `pre[right + 1] - pre[left]` |
| 区间异或 | `preXor[i + 1] = preXor[i] ^ nums[i]` | `preXor[right + 1] ^ preXor[left]` |
| 区间内违规点个数 | 先把违规位置记为 `1`，其余记为 `0` | 对标记数组求区间和 |
| 0、1 数量相等 | 把 `0` 变为 `-1`，把 `1` 变为 `1` | 区间和等于 `0` |
| 多个条件同时成立 | 把多个前缀量组合成一个状态 | 两端的组合状态相同 |

所以，使用前缀思想时最关键的往往不是“怎么计算 `pre`”，而是：

> 如何把题目条件转换成可累计、可比较的前缀状态。

---

## 3. 通用解题流程

### 第一步：把原数组转换成适合累计的信息

常见转换方式：

- 求区间和：保留原值。
- 统计某种元素：满足条件记为 `1`，否则记为 `0`。
- 判断相邻关系：相邻元素违规时记为 `1`。
- 平衡两类元素：一类记为 `1`，另一类记为 `-1`。
- 判断每个二进制位出现次数的奇偶性：使用异或。

### 第二步：定义前缀状态

先用一句话明确它的含义，例如：

```text
pre[i] 表示原数组前 i 个元素的总和。
```

定义清楚后再写递推式，能显著减少下标错误。

### 第三步：把区间条件写成前缀关系

设子数组为 `[left, right]`：

```text
区间和为 target：pre[right + 1] - pre[left] = target
                    pre[left] = pre[right + 1] - target

区间和能被 k 整除：pre[right + 1] % k = pre[left] % k

区间异或为 0：preXor[right + 1] = preXor[left]
```

这一步完成后，区间问题通常会变成“查找之前是否出现过某个前缀状态”。

### 第四步：根据问题目标选择保存方式

| 问题目标 | 应保存的内容 |
| --- | --- |
| 多次查询某个区间 | 完整前缀数组 |
| 判断某状态是否出现过 | `HashSet` |
| 统计合法子数组数量 | 状态出现次数 `HashMap<State, Count>` |
| 求最长合法子数组 | 状态第一次出现的位置 `HashMap<State, FirstIndex>` |
| 求最大区间差 | 最小或最大前缀值 |
| 多个条件同时满足 | 组合状态，例如 `(xor, balance)` |
| 首尾元素受限制且区间和最大 | 每种端点值对应的最小前缀和 |

### 第五步：确定“先查询还是先更新”

遍历顺序会影响子数组长度和是否把当前位置与自身匹配：

- 统计非空子数组时，通常先查询旧状态，再把当前状态加入哈希表。
- 求最长子数组时，只记录某状态第一次出现的位置，不要覆盖。
- 要求长度至少为 `2` 时，可以延迟加入前缀状态，只让当前位置匹配足够早的前缀。
- 把当前位置作为未来区间左端点时，应在处理完当前答案后再更新累计和。

## 4. 基础 Java 模板

推荐默认使用 `long` 保存前缀和，避免多个 `int` 累加后溢出。

```java
class PrefixSum {
    private final long[] pre;

    public PrefixSum(int[] nums) {
        int n = nums.length;
        pre = new long[n + 1];

        for (int i = 0; i < n; i++) {
            pre[i + 1] = pre[i] + nums[i];
        }
    }

    // 返回闭区间 [left, right] 的元素和
    public long query(int left, int right) {
        return pre[right + 1] - pre[left];
    }
}
```

若只在一道 LeetCode 题中使用，可以直接写成：

```java
int n = nums.length;
long[] pre = new long[n + 1];

for (int i = 0; i < n; i++) {
    pre[i + 1] = pre[i] + nums[i];
}

// 闭区间 [left, right]
long rangeSum = pre[right + 1] - pre[left];
```

### 复杂度

- 构建前缀和：时间复杂度 `O(n)`，空间复杂度 `O(n)`。
- 每次区间查询：时间复杂度 `O(1)`。
- 如果只需要边遍历边统计，通常可以用一个变量维护当前前缀状态，把空间降到 `O(1)`；使用哈希表时则通常为 `O(n)`。

## 5. 高频变式模板

### 5.1 前缀异或

异或满足 `x ^ x = 0`、`x ^ 0 = x`，因此重复的前缀部分可以被消去。

```java
int n = nums.length;
int[] preXor = new int[n + 1];

for (int i = 0; i < n; i++) {
    preXor[i + 1] = preXor[i] ^ nums[i];
}

// 闭区间 [left, right] 的异或值
int rangeXor = preXor[right + 1] ^ preXor[left];
```

### 5.2 统计和为 `target` 的子数组个数

若当前前缀和为 `sum`，则需要寻找之前出现过多少个 `sum - target`。

```java
Map<Long, Integer> count = new HashMap<>();
count.put(0L, 1);

long sum = 0;
long answer = 0;

for (int num : nums) {
    sum += num;
    answer += count.getOrDefault(sum - target, 0);
    count.put(sum, count.getOrDefault(sum, 0) + 1);
}
```

初始化 `count.put(0L, 1)` 是为了统计从下标 `0` 开始、其和恰好为 `target` 的子数组。

### 5.3 统计和能被 `k` 整除的子数组

两个前缀和对 `k` 的余数相同，它们的差就能被 `k` 整除。

```java
Map<Integer, Integer> count = new HashMap<>();
count.put(0, 1);

long sum = 0;
long answer = 0;

for (int num : nums) {
    sum += num;
    int remainder = (int) Math.floorMod(sum, k);

    answer += count.getOrDefault(remainder, 0);
    count.put(remainder, count.getOrDefault(remainder, 0) + 1);
}
```

`Math.floorMod(sum, k)` 可以把负前缀和的余数规范到非负范围，避免 Java 的负数取模问题。

### 5.4 统计区间异或为 `0` 的子数组个数

区间异或为 `0`，等价于区间两端的前缀异或相同。

```java
Map<Integer, Integer> count = new HashMap<>();
count.put(0, 1);

int xor = 0;
long answer = 0;

for (int num : nums) {
    xor ^= num;

    int oldCount = count.getOrDefault(xor, 0);
    answer += oldCount;
    count.put(xor, oldCount + 1);
}
```

### 5.5 求状态相同的最长子数组

如果两个位置的前缀状态相同，它们之间的状态变化量就是 `0`。为了让区间最长，应保存每个状态最早出现的位置。

```java
Map<Long, Integer> firstIndex = new HashMap<>();
firstIndex.put(0L, -1);

long state = 0;
int answer = 0;

for (int i = 0; i < nums.length; i++) {
    state += transform(nums[i]);

    if (firstIndex.containsKey(state)) {
        answer = Math.max(answer, i - firstIndex.get(state));
    } else {
        // 只保存第一次出现的位置
        firstIndex.put(state, i);
    }
}
```

例如“0 和 1 数量相同”时，可以令：

```java
state += nums[i] == 1 ? 1 : -1;
```

### 5.6 多个条件同时成立：组合状态

如果一个子数组既要求异或值为 `0`，又要求两类元素数量相等，就需要同时维护：

```text
state = (prefixXor, prefixBalance)
```

只有两个分量都相等，两个位置之间的子数组才同时满足全部条件。

可以使用以下方式作为哈希表的键：

- 定义 `record State(int xor, int balance)`。
- 在明确每个字段取值范围后进行位编码。
- 拼接成字符串虽然直观，但效率通常较低。

位编码时必须给每个字段预留足够位数并处理负数，否则不同状态可能得到相同的键。

### 5.7 最大子数组绝对和

任意子数组和都是两个前缀和之差，因此最大的绝对差一定来自所有前缀和中的最大值与最小值：

```java
long sum = 0;
long maxPrefix = 0;
long minPrefix = 0;

for (int num : nums) {
    sum += num;
    maxPrefix = Math.max(maxPrefix, sum);
    minPrefix = Math.min(minPrefix, sum);
}

long answer = maxPrefix - minPrefix;
```

### 5.8 修改一个固定长度区间后的最优值

这类题先计算原始总贡献，再枚举被修改的长度为 `k` 的窗口：

```text
修改后总值 = 原始总值 - 窗口原贡献 + 窗口新贡献
```

如果“原贡献”和“新贡献”来自不同数组，就分别构建前缀和：

```java
long[] oldPre = new long[n + 1];
long[] newPre = new long[n + 1];

for (int i = 0; i < n; i++) {
    oldPre[i + 1] = oldPre[i] + oldValue(i);
    newPre[i + 1] = newPre[i] + newValue(i);
}

long answer = oldPre[n];

for (int right = k; right <= n; right++) {
    int left = right - k;
    long oldPart = oldPre[right] - oldPre[left];
    long newPart = newPre[right] - newPre[left];
    answer = Math.max(answer, oldPre[n] - oldPart + newPart);
}
```

如果窗口只有一部分使用新规则，只需继续用前缀和拆分各段贡献。

### 5.9 首尾元素受限制时的最大子数组和

若当前右端点值为 `x`，并要求左端点值是 `x - k` 或 `x + k`，则：

```text
区间和 = 当前区间末尾的前缀和 - 左端点之前的前缀和
```

为了最大化区间和，应为每种可能的左端点值保存最小的“左端点之前的前缀和”。

```java
Map<Integer, Long> minPrefix = new HashMap<>();
long sumBefore = 0;
long answer = Long.MIN_VALUE;

for (int x : nums) {
    Long leftPrefix = minPrefix.get(x - k);
    if (leftPrefix != null) {
        answer = Math.max(answer, sumBefore + x - leftPrefix);
    }

    leftPrefix = minPrefix.get(x + k);
    if (leftPrefix != null) {
        answer = Math.max(answer, sumBefore + x - leftPrefix);
    }

    // 当前元素从此可以作为未来子数组的左端点
    minPrefix.merge(x, sumBefore, Math::min);
    sumBefore += x;
}

return answer == Long.MIN_VALUE ? 0 : answer;
```

### 5.10 有序数组中的距离和

对于非递减数组，在位置 `i` 处计算它与所有元素的绝对差：

```text
左侧贡献 = nums[i] * i - pre[i]
右侧贡献 = (pre[n] - pre[i + 1]) - nums[i] * (n - i - 1)
答案       = 左侧贡献 + 右侧贡献
```

```java
long[] pre = new long[n + 1];
for (int i = 0; i < n; i++) {
    pre[i + 1] = pre[i] + nums[i];
}

long[] answer = new long[n];
for (int i = 0; i < n; i++) {
    long left = (long) nums[i] * i - pre[i];
    long right = pre[n] - pre[i + 1]
            - (long) nums[i] * (n - i - 1);
    answer[i] = left + right;
}
```

## 7. 常见易错点

1. **混淆下标**：`pre[i]` 表示前 `i` 个元素，区间右端点要写成 `right + 1`。
2. **忘记初始状态**：计数模型通常需要 `map.put(0, 1)`；最长长度模型通常需要 `map.put(0, -1)`。
3. **负数取模**：使用 `Math.floorMod(sum, k)`，或写成 `(sum % k + k) % k`。
4. **覆盖最早位置**：求最长长度时，只在状态第一次出现时记录下标。
5. **计数时只加一**：一个状态之前出现 `count` 次，就会新增 `count` 个合法子数组，而不是只新增一个。
6. **忽略最短长度**：通过延迟加入前缀状态，保证匹配位置之间有足够距离。
7. **整数溢出**：前缀和、答案数量、乘法和距离和优先使用 `long`。
8. **哈希键冲突**：组合多个状态时，位编码必须预留足够空间；不确定时使用专门的状态对象。
9. **更新顺序错误**：先查询还是先存储会决定能否匹配自身以及区间是否为空。
10. **只会套区间和公式**：遇到计数、最长、最大值题时，真正要选择的是哈希表中保存“次数、最早位置还是最小前缀”。

## 8. 最终记忆框架

看到连续子数组或区间问题时，可以按下面的顺序思考：

```text
连续区间问题
    ↓
能否把条件转换成可累计的数值或状态？
    ↓
写出区间条件与两个前缀状态的关系
    ↓
只查询区间 → 前缀数组
判断存在性 → HashSet
统计数量   → 状态出现次数
求最长长度 → 状态最早位置
求最大区间 → 最小/最大前缀值
多个条件   → 组合前缀状态
```

最值得记住的不是某一道题的代码，而是这一句：

> **先做状态转换，再推导前缀关系，最后根据“查询、计数、最长或最值”选择保存内容。**
