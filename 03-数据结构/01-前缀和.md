#### 题目 1

![题目截图](./figure/Pasted%20image%2020260905160147.png)

**思路**
要注意的问题：防止start出界，因为要求[start,i]的元素和
本质上=pre[i]-pre[start-1],但是怕start出界，就让pre长度为n+1;pre[0] = 0 ,前零个元素和依旧为0

**解答**

```java
class Solution {

    public int subarraySum(int[] nums) {

        int ans = 0;

        int n = nums.length;

        // 1. 构建标准前缀和数组，长度为 n + 1

        int[] prefix = new int[n + 1];

        for (int i = 0; i < n; i++) {

            prefix[i + 1] = prefix[i] + nums[i];

        }

        // 2. 遍历每个下标 i，计算对应的子数组和

        for (int i = 0; i < n; i++) {

            int start = Math.max(0, i - nums[i]);

            // 区间 [start, i] 的和 = prefix[i + 1] - prefix[start]

            ans += prefix[i + 1] - prefix[start];

        }

        return ans;

    }

}

```

int[] sumC = new int[n+1];

class Solution {

    public int[] vowelStrings(String[] words, int[][] queries) {



        int n = words.length;

        int[] cnt = new int[n];

        for(int i = 0; i<n;i++){

            cnt[i] = f(words[i]);

        }

        int[] sumC = new int[n+1];

        for(int i =0 ;i<n;i++){

            sumC[i+1] = sumC[i]+cnt[i];
        }
        int m = queries.length;

        int[] ans = new int[m];

        for(int j = 0;j<m;j++){

            int[] k = queries[j];

           ans[j]=sumC[k[1]+1]-sumC[k[0]];

        }
        return ans;
    }
    private int f(String word) {

    if (word == null || word.isEmpty()) return 0;

    String vowels = "aeiou";

    char first = word.charAt(0);

    char last = word.charAt(word.length() - 1);

    // 如果首字母在 vowels 中能找到（索引不为 -1），且尾字母也能找到

    if (vowels.indexOf(first) != -1 && vowels.indexOf(last) != -1) {

        return 1;
    }
    return 0;
}
}

class Solution {

    public int[] xorQueries(int[] arr, int[][] queries) {

        int n = arr.length;

        // 1. 构建前缀异或数组

        // 长度为 n + 1，prefix[0] 默认为 0

        int[] prefix = new int[n + 1];

        for (int i = 0; i < n; i++) {

            // prefix[i+1] 代表 arr[0]...arr[i] 的异或和

            prefix[i + 1] = prefix[i] ^ arr[i];

        }

        // 2. 处理查询并填充结果

        int[] result = new int[queries.length];

        for (int i = 0; i < queries.length; i++) {

            int L = queries[i][0];

            int R = queries[i][1];

            // 利用前缀异或性质计算区间 [L, R] 的异或值

            // 公式: prefix[R + 1] ^ prefix[L]

            result[i] = prefix[R + 1] ^ prefix[L];

        }

        return result;

    }

}

#### 题目 4

![题目截图](./figure/Pasted%20image%2020260905164940.png)

**思路**

利用一个前缀和数组来维护总数组nums，有多少个违规点：该点与前后数据奇偶性相同，那么pre数组+1
也就是说pre数组就像一个阶梯数组一样，每一个跳变就是一个违规点

**解答**

```java
class Solution {
    public boolean[] isArraySpecial(int[] nums, int[][] queries) {
        int n = nums.length;
        // 1. 构建前缀和数组
        // prefix[i] 表示 nums[0...i] 中，相邻元素奇偶性相同的对数
        int[] prefix = new int[n];
        // prefix[0] 默认为 0，因为只有一个元素无法构成对
        for (int i = 1; i < n; i++) {
            // 如果当前元素和前一个元素奇偶性相同，则违规数 +1
            // 否则违规数不变（继承 prefix[i-1]）
            if (nums[i] % 2 == nums[i-1] % 2) {
                prefix[i] = prefix[i - 1] + 1;
            } else {
                prefix[i] = prefix[i - 1];
            }
        }
        int m = queries.length;
        boolean[] answer = new boolean[m];
        // 2. 处理每个查询
        for (int j = 0; j < m; j++) {
            int from = queries[j][0];
            int to = queries[j][1];
            // 计算子数组 nums[from...to] 内部的违规对数量
            // 我们只需要看 prefix[to] 和 prefix[from] 的差值
            // 为什么是 prefix[from] 而不是 prefix[from-1]？
           // 因为 prefix[i] 记录的是 i 和 i-1 的关系。
            // 子数组从 from 开始，意味着 from 和 from-1 的关系不在考察范围内。
            // 我们要考察的是 (from, from+1], (from+1, from+2] ... (to-1, to]
            // 也就是 prefix[to] - prefix[from]
            int violations = prefix[to] - prefix[from];
            if (violations == 0) {
                answer[j] = true;
            } else {
                answer[j] = false;
            }
        }
        return answer;
    }
}

```

#### 题目 5

![题目截图](./figure/Pasted%20image%2020260905170103.png)

**思路**

依旧使用前缀和，求解nums[l]+.....+nums[r]的绝对值最大值，本质就是前缀和pre[r+1]-pre[l]的差值的最大值，所以只需要维护pre中的最大值最小值即可

**解答**

```java
class Solution {

    public int maxAbsoluteSum(int[] nums) {

        int sum = 0;

        int maxPrefix = 0; // 初始化为0，对应空前缀

        int minPrefix = 0; // 初始化为0，对应空前缀

        for (int num : nums) {

            sum += num;

            // 更新前缀和的最大值和最小值

            maxPrefix = Math.max(maxPrefix, sum);

            minPrefix = Math.min(minPrefix, sum);

        }

        // 最大绝对值即为最大前缀和减去最小前缀和

        return maxPrefix - minPrefix;

    }

}

```

#### 题目 6

![题目截图](./figure/Pasted%20image%2020260905233118.png)

**思路**

计算两个前缀和数组：

定义数组 c，其中 c[i]=prices[i]⋅strategy[i]。计算 c 的前缀和，记作 sum。
计算 prices 的前缀和，记作 sumSell。
关于前缀和数组的详细定义，请看 前缀和。
如果不修改，答案为 sum[n]。

如果修改，枚举修改子数组 [i−k,i−1]。修改后的利润由三部分组成：

[0,i−k−1] 的 prices[i]⋅strategy[i] 之和，即 sum[i−k]。
[i,n−1] 的 prices[i]⋅strategy[i] 之和，即 sum[n]−sum[i]。
[i−k/2,i−1] 的 prices[i] 之和，即 sumSell[i]−sumSell[i−k/2]。
总和为

sum[i−k]+sum[n]−sum[i]+sumSell[i]−sumSell[i−k/2]
用上式更新答案的最大值。

**解答**

```java
class Solution {

    public long maxProfit(int[] prices, int[] strategy, int k) {

        int n = prices.length;

        long[] sum = new long[n+1];

        long[] sumSell = new long[n+1];

        for(int i = 0;i<n;i++){

            sum[i+1] = sum[i] + prices[i]*strategy[i];

            sumSell[i+1] = sumSell[i] + prices[i];

        }



        long ans = sum[n];

        for(int i = k ;i<=n;i++){

            long res = sum[i-k] + sum[n] - sum[i] + sumSell[i] - sumSell[i-k/2];

            ans = Math.max(ans,res);

        }

        return ans;

    }

}

```

#### 题目 7

![题目截图](./figure/Pasted%20image%2020260907094932.png)

**思路**

### 📝 LeetCode 974. 和可被 K 整除的子数组

**核心思想**：前缀和 + 同余定理 + 哈希表

#### 1. 数学原理 (同余定理)

- 若 `(P[j] - P[i]) % K == 0`，则 `P[j] % K == P[i] % K`。
- **结论**：只要两个前缀和对 `K` 取模的**余数相同**，它们之间的子数组和就能被 `K` 整除。

#### 2. 算法步骤

1. **初始化**：
    - `map = {0: 1}` (关键！处理从索引 0 开始的合法子数组)。
    - `sum = 0`, `ans = 0`。
2. **遍历数组**：
    - 累加前缀和：`sum += num`。
    - 计算余数 (处理负数)：`rem = (sum % k + k) % k`。
3. **统计与更新**：
    - **查表**：`ans += map.getOrDefault(rem, 0)` (之前出现过几次余数 `rem`，就新增几个合法子数组)。
    - **存表**：`map.put(rem, count + 1)`。

#### 3. 复杂度

#### ⚠️ 易错点

1. **负数取模**：Java/Python 中负数取模可能为负，必须 `(x % k + k) % k` 修正为正余数。
2. **初始值**：`map.put(0, 1)` 不能漏，否则漏掉前缀和本身能被 K 整除的情况。
3. **累加逻辑**：是 `ans += count`，不是 `ans++`。

**解答**

```java
class Solution {

    public int subarraysDivByK(int[] nums, int k) {

        int n = nums.length;

        int[] pre = new int[n+1];

        for(int i =0;i<n;i++){

            pre[i+1] = pre[i] + nums[i];

        }



        int ans=0;

        Map<Integer,Integer> map = new HashMap<>();

        map.put(0,1);



        for(int i =0 ;i<n;i++){

            int res = (pre[i+1]%k+k)%k;

            if(map.containsKey(res)){

                ans+=map.get(res);

            }

            map.put(res,map.getOrDefault(res,0)+1);

        }

        return ans;

    }

}

```

#### 题目 8

![题目截图](./figure/Pasted%20image%2020260907100528.png)

**思路**

这道题也可以用hashmap解答，也可以使用hashset，因为这道题只需要返回输出true Or false即可
那么对于前缀和：
### 1. 核心数学原理：同余定理

这道题的本质是寻找子数组 `nums[j...i-1]`，使得其和是 `k` 的倍数。  
子数组和可以用前缀和表示：

Sum(j,i−1)=prefix[i]−prefix[j]Sum(j,i−1)=prefix[i]−prefix[j]

我们要让这个差值是 k 的倍数：

(prefix[i]−prefix[j])%k==0(prefix[i]−prefix[j])%k==0

⇒prefix[i]−prefix[j]=n×k⇒prefix[i]−prefix[j]=n×k

⇒prefix[i]=prefix[j]+n×k⇒prefix[i]=prefix[j]+n×k

**两边同时模 k ：**

prefix[i]%k=(prefix[j]+n×k)%kprefix[i]%k=(prefix[j]+n×k)%k

因为 n×k 能被 k 整除，模运算后为 0，所以：

prefix[i]%k=prefix[j]%kprefix[i]%k=prefix[j]%k

**结论**：  
只要两个前缀和对 kk 取模的**余数相等**，它们之间的差值就是 k 的倍数。

**解答**

```java
class Solution {

    public boolean checkSubarraySum(int[] nums, int k) {

        int n = nums.length;

        int[] sum = new int[n + 1];

        for (int i = 1; i <= n; i++) sum[i] = sum[i - 1] + nums[i - 1];

        Set<Integer> set = new HashSet<>();

        for (int i = 2; i <= n; i++) {

            set.add(sum[i - 2] % k);

            if (set.contains(sum[i] % k)) return true;

        }

        return false;

    }

}

```

#### 题目 9

![题目截图](./figure/Pasted%20image%2020260908100356.png)

**思路**

示例 1 说 [4,3,1,2,4] 是个美丽子数组，来看看为什么。

把每个数都写成二进制：
100
011
001
010
100
一次操作，可以把某一列中的两个 1 都变成 0。
多次操作，可以把某一列中的偶数个 1 都变成 0。
所以，如果每一列都有偶数个 1，我们就能把所有数都变成 0。反之，如果某一列有奇数个 1，就不行。
设一列的元素和为 s，那么需要满足smod2=0,其中 smod2 可以用异或运算代替，因为一堆 0 和 1 的异或和，等同于这些数相加再模 2。
推广到多个列（多个比特位）：
如果每一列都有偶数个 1，那么所有数的异或和必然等于 0。
如果某一列有奇数个 1，那么所有数的异或和必然不等于 0。
所以美丽子数组等价于：子数组的异或和等于 0。
由于异或的运算性质类似加法，可以用  560. 和为 K 的子数组 的做法（前缀和+哈希表）解决。本题相当于 k=0。

**解答**

```java
class Solution {

    public long beautifulSubarrays(int[] nums) {

        long ans = 0;

        int s = 0;

        Map<Integer,Integer> cnt = new HashMap<>(nums.length+1);

        cnt.put(0,1);



        for(int x : nums){

            s ^= x;

            int c = cnt.getOrDefault(s,0);

            ans += c;

            cnt.put(s,c+1);

        }

        return ans;

    }

}

```

class Solution {

    public int maxBalancedSubarray(int[] nums) {

        int n = nums.length;

        int ans = 0;

        int xor = 0;

        int diff = n;

        Map<Long,Integer> pos = new HashMap<>(n+1,1);

        pos.put((long) xor << 20 | diff , -1 );

        for(int i = 0;i<n;i++){

            xor ^= nums[i];

            diff += nums[i]%2 != 0 ? 1 : -1;

            long key  = (long) xor << 20 | diff;

                ans = Math.max(ans , i-j);

            }

            else{

                pos.put(key,i);

            }

        }

        return ans;

    }
